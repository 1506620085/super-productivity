# 打包应用

如何为 Super Productivity 构建可分发的安装包（Electron）。

## 前置条件

- 已配置开发环境（[[2.11-Run-the-Development-Server]]）
- Node.js 20+

## 构建安装包

```bash
npm run dist
```

该命令使用 [electron-builder](https://github.com/electron-userland/electron-builder)，并为当前平台（以及已配置的其他平台）生成安装程序。

## 自定义平台与选项

- **配置文件：** 编辑 `electron-builder.yaml` 以设置共享的打包选项。平台特定覆盖位于 `build/` 下，包括用于 Mac App Store 构建的 `electron-builder.mas*.yaml` 文件。
- **CLI：** 使用 [electron-builder CLI](https://www.electron.build/cli) 进行一次性构建（例如不同架构或格式）。
