# 管理任务集成

本 How-To 说明如何设置并使用议题集成（Jira、GitHub、GitLab 等）与日历，以从外部系统导入并关联任务。关于集成工作方式的概览，见 [[4.24-Integrations]]。关于各提供方对工作日志、状态流转、子任务及其他功能的支持对比，见 [[3.07-Issue-Integration-Comparison]]。

## 打开议题与日历面板

**issue provider panel**（Integrations & Calendars）是一个侧面板，列出你已配置的提供方，并允许搜索并将议题或日历事件添加为任务。

**从页眉：** 点击用于显示或隐藏议题提供方面板的按钮。其工具提示为 **Show/hide issue provider panel**。在桌面上它出现在顶栏；在移动端则在侧边菜单中。

**使用键盘：** 若已配置，使用「Show/hide issue provider panel」的快捷键（见 [[3.02-Settings-and-Preferences]] → Keyboard 与 [[3.03-Keyboard-Shortcuts]]）。

## 添加新集成（议题提供方或日历）

1. 打开议题提供方面板（见上文）。
2. 点击**最后一个标签页** — 带有 **plus (add)** 图标的那个。视图会显示两个部分：**Connect Calendar** 与 **Setup Issue Provider**。
3. **对于日历：** 在 **Connect Calendar** 下，点击 **Google Calendar**、**Outlook 365** 或 **iCal Other**。会打开配置对话框（例如 iCal 的 URL，或 Google/Outlook 的 OAuth）。填写详细信息并保存。
4. **对于议题提供方：** 在 **Setup Issue Provider** 下，点击你想要的提供方：**Jira**、**Trello**、**GitHub**、**Redmine**、**GitLab**、**CalDAV**、**Open Project**、**Gitea**、**Linear**、**ClickUp** 或 **Plainspace**。会打开配置对话框。输入必填字段（主机 URL、令牌或密码、项目/仓库 ID 等 — 具体字段取决于提供方）。保存以创建集成。对于 **Plainspace**（协作），最简便的路径是项目菜单 — 见下方 [使用 Plainspace 协作项目](#collaborate-on-a-project-with-plainspace)。

### 日历集成：iCal 与 CalDAV（例如 Nextcloud）

**iCal** 与 **CalDAV** 是两种不同的集成，需要**不同类型的链接**：

- **iCal (Calendar)：** 使用**订阅**或**导出** URL。无需登录。应用在 Schedule/Planner 中显示**事件**（VEVENT）。在 **Nextcloud** 中，使用 **“Copy subscription link”**，并将其粘贴到应用中的 **“URL of the iCal source”**。**不要**将 “Copy private link” 用于 iCal——那是给 CalDAV 用的。
- **CalDAV：** 使用你的用户与日历的 **CalDAV URL**，并输入**用户名和密码**。应用显示**任务/待办**（VTODO）。对于已导入的 VTODO，完成状态、标题与备注可分别配置为 **off**、**pull only**、**push only** 或 **both**。在 Super Productivity 内创建的任务**不会**作为新的 VTODO 上传。在 **Nextcloud** 中，使用 **“Copy private link”**（或 CalDAV 日历 URL，例如 `…/remote.php/dav/calendars/<USER>/<CALENDAR>/`）。**不要**将订阅链接用于 CalDAV。

若集成「不工作」，请检查你是否使用了正确的链接与正确的提供方（iCal 与 CalDAV）。更多细节见 [[4.24-Integrations]] 与 [[3.07-Issue-Integration-Comparison]]。

对于 **CalDAV Events** 日历列表，请先输入服务器 URL、用户名与密码，再点击 **Load Options**，然后选择日历。在选项加载完成前，日历下拉框保持禁用。支持服务器根（例如 Nextcloud 的 `https://host/remote.php/dav`）以及特定的 calendar-home URL。若未找到日历，请检查凭据，并确认该账户至少有一个可用的事件日历。

保存后，面板中会出现该提供方的新**标签页**。你可以拥有同一类型的多个实例（例如两个 Jira 配置），并通过拖拽重新排列标签页。

### Azure DevOps 与自托管 TFS URL

对于 **Azure DevOps**，在 **Host** 中输入完整的组织或集合 URL。对于 Azure DevOps Services，形如 `https://dev.azure.com/<organization>`。对于自托管 Azure DevOps Server/TFS，可包含集合路径，例如 `https://server:8080/tfs/DefaultCollection`。单独的 **Project** 字段仍为必填。

## 将议题或日历项添加为任务

1. 打开议题提供方面板，并选择该提供方的**标签页**（例如 Jira 或 GitHub）。
2. **对于议题提供方：** 在 **Search** 字段中输入查询（语法取决于提供方；可能会显示提示或搜索语法链接）。匹配的议题会列出。点击议题旁的 **add (plus)** 按钮，即可将其作为任务添加到当前项目。该任务会与该议题关联。
3. **对于日历（例如 iCal）：** 标签页可能显示议程或事件列表。使用该标签页中的控件将事件添加为任务或打开它，具体取决于日历集成。

从面板添加的任务会创建在**当前项目**中（或为该提供方设置的默认项目；见下文）。

## 编辑或重新配置集成

**从提供方标签页：** 在提供方标签页的**页眉**中有一个 **settings (gear)** 图标。点击即可打开同一配置对话框，并更改主机、令牌、项目或其他选项。保存以应用。

**从标签页标签：** **长按**（或长点）提供方的**标签页**（带有提供方图标与首字母的标签页）。配置对话框会打开。这在移动端或标签页已选中时很有用。

## 为集成设置默认项目

当提供方设置了默认项目时，从该提供方标签页添加的新议题会创建在该项目中。在提供方标签页的**页眉**中，你可能会看到一个箭头与项目名称；那就是当前默认值。要更改它，打开该提供方的 **settings**（齿轮图标或长按标签页），并在对话框中设置默认项目（若提供方支持）。

## 从添加任务栏添加已有议题（搜索模式）

你也可以在不打开议题面板的情况下添加议题（以及已有任务）：

1. 打开 **add task bar**（例如 **Shift+A** 或 “Add new task” 按钮）。
2. 点击 **search** 图标或按 **Ctrl+2**（若已配置）以切换到 **issue search** 模式。占位符变为 “Add existing task or issues…”。
3. 输入以在已配置的提供方以及你的任务/归档中搜索。从列表中选择一个议题，即可将其作为关联任务添加到当前上下文。

关于添加任务栏与搜索模式的更多内容，见 [[2.03-Add-Tasks]]。

## Collaborate on a Project with Plainspace

[Plainspace](https://plainspace.org) 是 Super Productivity 的可选协作层：它将本地项目变为**共享 Space**，以便你与他人共同处理。分配给你的任务会自动导入，完成状态、标题与计划安排双向保持同步。这是一项网络功能 — 共享项目中的任务数据会离开你的设备；你的其他项目与核心离线使用不受影响。

**共享现有项目：**

1. 打开项目的 **context menu**（侧边栏中项目旁的 **⋮** 菜单，或项目页眉菜单）。
2. 点击 **Collaborate on Plainspace**。
3. 若尚未连接，引导对话框会要求提供 Plainspace **API token**（`pat_…`）。在 Plainspace 中于某个 Space → **People → Advanced → API tokens** 下创建，然后粘贴。
4. 选择为此项目**创建新 Space** 或**关联现有** Space，然后确认。会创建绑定的 Plainspace 提供方，分配给你的任务开始导入。

**在创建时共享：** 创建项目时，在创建项目对话框中启用 **Collaborate on this project on Plainspace**，即可一步完成相同操作。

项目一旦共享，该项目的 **Collaborate on Plainspace** 菜单项会被隐藏。Space 中未认领的任务会出现在工作视图的 **claim pool** 中，你可以在那里将其认领到自己的列表。

## 项目级集成设置

某些集成可**按项目**配置（例如使用哪个 Jira 项目）。打开该项目的 **Project settings**（通过项目菜单或侧边栏），并查找 **Issue Integration** 或特定于提供方的部分。你可以在那里将项目附加到给定议题提供方，或覆盖该项目的集成设置。

## 故障排除

- **搜索中无议题 / “Check your config!”：** 打开提供方的 **settings**（标签页中的齿轮），检查主机 URL、令牌与项目/仓库 ID。若对话框提供连接测试，请进行测试。对于 **web app** 中的 Jira，可能需要浏览器扩展；若是如此，标签页会显示提示。
- **提供方标签页被禁用：** 当提供方被禁用时，标签页会变灰。长按标签页（或从其他路径使用设置齿轮）打开对话框并重新启用。
- **议题未更新：** 某些提供方按间隔轮询更新。检查提供方配置中是否有 “Check for updates every X” 或轮询间隔等选项。在标签页中刷新列表也可能触发更新。
