# Wiki 质量保证与维护

Wiki 的 pull request 会在 CI 中运行 Markdown lint 与本地链接校验。本地检查器会校验
Markdown 链接、HTML 的 `href`/`src` 属性、图片以及 Wiki 链接；也会拒绝 Wiki
链接别名——对本仓库而言，GitHub 会错误渲染这类别名。

提交前请运行可用的检查：

```bash
npm run docs:check-links
pymarkdownlnt --disable-rules line-length,no-inline-html scan docs/wiki
```

`pymarkdownlnt` 在本地为可选，但 CI 要求必须通过。链接检查器无第三方依赖。

外部 URL 不会自动爬取，因为瞬时网络故障不适合作为 pull request 门禁。请打开你新增
或修改的任意外部链接，优先使用稳定的一手来源，并用仍在维护的来源替换死链，而不是
换成另一个聚合站。若能区分临时故障与持久失效，可另行增加定时外部链接报告。
