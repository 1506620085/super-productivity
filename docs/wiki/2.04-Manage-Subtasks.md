# 管理子任务

关于子任务如何建模以及适用哪些限制（例如重复任务与议题关联任务不能作为子任务），见 [[4.11-Subtasks]]。

## 为任务添加子任务

**从上下文菜单：** 右键点击任务，然后点击 **Add subtask**。（此选项仅对未完成的父任务显示。）

**从任务详情面板：** 打开任务（点击它，使右侧详情面板打开）。在 **Subtasks** 部分底部，点击 **Add subtask** 按钮（加号图标与 "Add subtask" 标签）。

**使用键盘：** 聚焦父任务（点击或使用方向键），然后按 **A**（「Add subtask」的默认快捷键）。更改或确认按键见 [[3.03-Keyboard-Shortcuts]]。

## 在任务内重新排序子任务

**使用键盘：** 聚焦要移动的子任务。使用：

- **Ctrl+Shift+Arrow Up** — 在列表中上移一位
- **Ctrl+Shift+Arrow Down** — 在列表中下移一位
- **Ctrl+Alt+Arrow Up** — 移到子任务列表顶部
- **Ctrl+Alt+Arrow Down** — 移到子任务列表底部

快捷键可在 [[3.02-Settings-and-Preferences]] 中配置。

**通过拖拽：** 用任务左侧的 **drag handle**（抓取图标）抓住任务，并在同一父任务的子任务列表中上下拖动。放到你想要的新位置。

**从右键菜单：** 右键点击未完成的任务，选择 **Move to top** 或 **Move to bottom**，在其当前列表中移动——顶层（父）任务对应常规或 backlog 列表，子任务对应父任务的子任务列表。对于子任务，这些条目出现在父任务下显示子任务的位置；在标签或 Today 列表中，请改用键盘快捷键。

## 将子任务移到另一个父任务

用 **drag handle** 拖动子任务，放到目标父任务上，或放入该父任务的子任务列表。该子任务成为新父任务的子项，并保持同一项目（子任务继承父任务的项目）。

## 将子任务转换为主任务

右键点击子任务，然后点击 **Convert to parent task**。该子任务成为同一项目中的顶层任务。重复任务与议题关联任务不能转换为子任务；见 [[4.11-Subtasks]]。

## 显示或隐藏已完成的子任务

在**父任务行**上、其子任务列表旁，有一个小的**切换按钮**（加号/减号图标）。其工具提示为 "Toggle subtask visibility."。每次点击会循环：

1. **Show all** — 显示所有子任务
2. **Hide done** — 隐藏已完成的子任务
3. **Hide all** — 折叠子任务列表

子任务被隐藏时，会出现类似 "+ 3 done sub tasks" 或 "+ 5 sub tasks" 的行；点击即可展开并再次显示子任务。

当父任务处于焦点时，也可以使用 **Expand subtasks** 与 **Collapse subtasks** 键盘快捷键（见 [[3.03-Keyboard-Shortcuts]]）。
