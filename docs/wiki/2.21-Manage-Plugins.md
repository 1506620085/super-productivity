# 管理插件

插件可为 Super Productivity 添加集成、控件与自定义视图。
它们是可执行代码，对你的应用数据有显著访问权限，且
**未与应用强沙箱隔离**。仅安装你信任其来源与作者的插件。

## 安装并检查插件

1. 打开 **Settings** → **Plugins**。
2. 阅读安全警告，并检查插件列出的权限、钩子与网络主机。
3. 在 **Install Plugin** 下，选择一个插件 ZIP 文件。
4. 用开关启用插件；若有设置按钮，可进行配置。

社区插件未经 Super Productivity 团队审核或保证。安装前请备份数据；见
[[2.02-Restore-Data-From-Backup]]。

## 理解信任边界

- 宿主侧的 `plugin.js` 代码在应用渲染进程中运行，可读取或更改应用数据。
- Iframe 插件以经过过滤的 Plugin API 作为受支持的接口，但它们与宿主同源。iframe 桥接并非安全边界。
- 已上传插件的 Manifest 名称、版本与权限由插件自身提供。请审查源码，而非仅依赖标签。

## Node.js 与完整机器访问权限

`nodeExecution` 仅在 Electron 桌面应用中可用。它允许插件以与你的用户账户相同的文件与进程访问权限运行原生代码。

Electron 主进程在授予此权限前会显示原生的 Allow/Deny 提示。已上传的插件被标记为未验证的第三方代码，除非你已检查并信任源码，否则安全的选择是 **Deny**。
对已上传插件的同意仅限于该设备，并在插件被禁用、移除或再次上传时清除。

Web 应用无法授予 `nodeExecution`。

## 禁用或移除插件

- 关闭插件的开关以禁用它，并撤销其原生执行同意。
- 使用 **Remove** 卸载已上传的插件。
- 若可疑行为仍在继续，请在禁用或移除插件后重启应用。
