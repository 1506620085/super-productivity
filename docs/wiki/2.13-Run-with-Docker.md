# 使用 Docker 运行

如何在 Docker 中运行 Super Productivity Web 应用，以及如何使用 WebDAV 集成。

## 仅运行 Web 应用

```bash
docker run -d -p 80:80 super-productivity/super-productivity:latest
```

打开 [http://127.0.0.1](http://127.0.0.1)。镜像默认匹配宿主机平台。使用 `--platform` 可指定其他架构（例如 `linux/amd64`、`linux/arm64`、`linux/arm/v7`）。

数据存储在浏览器中；容器不提供持久化存储。

## 与 WebDAV 一起运行

若要在同一主机上同时提供应用与 WebDAV 后端：

1. 将仓库文件复制到某个文件夹（例如 `sp/`）：

   ```bash
   git clone https://github.com/super-productivity/super-productivity.git
   mkdir -p sp
   cp super-productivity/docker-compose.yaml sp/
   cp super-productivity/webdav.yaml sp/
   cd sp
   ```

2. 编辑 `webdav.yaml`：设置用户名、密码，以及 `/data` 下的每用户目录，以便用户数据相互隔离。

3. 启动整个栈：

   ```bash
   docker compose pull
   docker compose up -d
   ```

4. 打开 [http://127.0.0.1](http://127.0.0.1) 访问应用。在应用中配置 WebDAV 同步，Base URL 为：`http://127.0.0.1/webdav/`。

## 其他 Docker 选项

可以向应用容器传入环境变量，以在设置页面预填 WebDAV（或其他同步）配置。变量列表见仓库中的 `docker-compose.yaml`。
