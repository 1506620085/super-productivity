# 通过 rclone + WebDAV 同步到 Proton Drive

本指南说明如何在桌面上将 Super Productivity 同步到 **Proton Drive**。Proton Drive 没有官方的第三方同步 API，因此做法是运行一个小型本地桥接 —— [rclone](https://rclone.org/protondrive/) 将你的 Proton Drive 暴露为本地 WebDAV 端点 —— 然后将 Super Productivity 现有的 **WebDAV** 提供商指向它。应用中没有专门的 “Proton Drive” 选项；你需要针对本地地址配置 **WebDAV** 提供商。

> **请先阅读 —— 实验性，无支持。** 此方案依赖 rclone **由社区维护、逆向工程**的 Proton Drive 后端。Proton 官方不支持第三方访问，且每当 Proton 更改其 API 或加密时，该后端都可能失效。与通用 WebDAV 同步类似（见 [[2.08-Choose-Sync-Backend]]），此路径为**实验性功能，按原样提供，不提供支持**。大多数问题来自 rclone/Proton 侧或你的本地设置 —— 请与 [rclone 社区](https://forum.rclone.org/)一起排查，**不要将其作为 bug 报告给 Super Productivity**。若你需要完全受支持的云同步，请改用 **Dropbox** 或 **SuperSync**。始终保留备份（见 [[2.02-Restore-Data-From-Backup]]）。

**仅限桌面端（Electron）。** 桥接需要本地 rclone 进程，因此在 Web 应用或移动端上不可用。

## 工作原理

```txt
Super Productivity  →  WebDAV provider  →  http://127.0.0.1:<port>  →  rclone serve webdav  →  Proton Drive
```

你的 Proton 登录信息（包括 2FA 与邮箱密码）仅保存在 rclone 自己的配置中。Super Productivity 从不查看或存储你的 Proton 凭据 —— 它只与本地 WebDAV 端点通信。

## 1. 安装 rclone

[安装 rclone](https://rclone.org/downloads/)，并确保它位于系统 `PATH` 中（或记下可执行文件的完整路径）。验证其可用：

```sh
rclone version
```

## 2. 创建 Proton Drive remote

在终端中运行：

```sh
rclone config
```

创建一个类型为 **protondrive** 的新 remote。提示会引导你完成 Proton 登录，包括 2FA 以及（若有）单独的邮箱密码。为 remote 起一个名称 —— `protondrive` 是不错的默认值。

确认已配置：

```sh
rclone listremotes
# should include: protondrive:
```

## 3. 启动本地 WebDAV 桥接

将 rclone 作为绑定到 loopback 的本地 WebDAV 服务器运行，使用你选择的**固定**端口与凭据（以便一次性配置应用）：

```sh
rclone serve webdav protondrive: --addr 127.0.0.1:8585 --user sp --pass "choose-a-strong-password"
```

说明：

- `--addr 127.0.0.1:8585` 仅绑定到 **loopback** —— 桥接无法从其他机器访问。可选择任意空闲端口。
- 此处的 `--user` / `--pass` 是仅用于桥接的本地凭据；与你的 Proton 账户无关。仍请使用强密码。
- 同步期间请保持该进程运行。若要在重启后继续运行，请将 rclone 设置为后台服务 / 自启动项 —— 参见 [rclone serve 文档](https://rclone.org/commands/rclone_serve_webdav/) 以及你操作系统的服务管理器。

## 4. 在 Super Productivity 中配置 WebDAV 提供商

1. 打开 **Settings** → **Sync & Backup** → **Sync**。
2. 将 **Sync provider** 设为 **WebDAV**。
3. 填写：
   - **WebDAV Base URL**：`http://127.0.0.1:8585`
   - **Username**：`--user` 的值（例如 `sp`）
   - **Password**：`--pass` 的值
   - **Sync Folder Path**：用于存放同步文件的文件夹，例如 `/super-productivity`
4. （推荐）设置 **client-side encryption key**，以便同步文件在静态存储时加密。
5. 点击 **Test Connection**，然后启用同步。

完成 —— Super Productivity 现在通过本地桥接，使用标准 WebDAV 流水线同步到 Proton Drive。

## 保持运行

应用同步时，桥接必须处于运行状态。若 `rclone serve` 未运行，同步将无法连接（这是预期行为）。常见做法：

- 工作前手动启动。
- 作为后台服务运行（Linux 上的 systemd 用户服务、macOS 上的 Launch Agent、Windows 上的计划任务/启动项）。

若更改了端口、凭据或 remote，请同步更新 WebDAV 设置。

## 加密

Proton Drive 在 Proton 侧对你的数据端到端加密。从应用到本地桥接的这一跳是明文 HTTP，但不会离开你的机器（仅 loopback）。启用 Super Productivity 的 **client-side encryption key** 会在数据到达 rclone 之前额外加密同步文件内容 —— 推荐启用。

## 故障排除

- **“Connection failed” / 无法访问服务器** → 确保 `rclone serve webdav …` 仍在运行，且 Base URL/端口匹配。
- **登录、2FA、邮箱密码或 “remote not found” 问题** → 这些属于 rclone/Proton 范畴。重新运行 `rclone config`，用 `rclone lsd protondrive:` 测试，并在 [rclone 论坛](https://forum.rclone.org/)提问。这些**不是** Super Productivity 的 bug。
- **同步曾正常，但 Proton 变更后突然停止** → 逆向工程的后端可能需要更新 rclone。请先更新 rclone。
- **上传失败或文件看起来被截断** → 某些云后端在启用写入缓存时上传更可靠。在 `rclone serve webdav` 命令中添加 `--vfs-cache-mode writes` 并重启桥接。
