# 指标

Super Productivity 中的指标是**按日且基于上下文的数据**，用于复盘你如何工作：你输入或应用记录的原始输入（例如专注会话、影响评分、精力签到、反思），以及从这些数据**推导**的值（例如生产力与可持续性分数、日期范围内的汇总、趋势指示器）。应用**持久化**原始每日字段，并按需**计算**分数、汇总与图表，以便你既能看到「那天发生了什么」，也能看到「随时间如何比较」。了解什么是存储的、什么是计算的、每个指标代表什么，以及指标在应用中出现在何处，有助于你有效使用评估表、指标视图与分享。

反思是持久化每日字段之一；请参阅 [[4.18-Reflection]]。专注会话既进入持久化数据，也进入生产力/可持续性分数；请参阅 [[4.15-Timers-and-Focus-Mode]]。评估与指标设置在 [[3.02-Settings-and-Preferences]]。

## 追踪哪些每日指标？

应用按两类追踪**每日**数据：**持久化**（作为该日记录的一部分存储）与**计算**（在你打开视图或报告时计算）。

### 持久化每日字段

每一天有由日期标识的**指标记录**。应用存储：

- **日期** — 该记录所属的日子。
- **专注会话** — 该日来自 Focus Mode 的专注会话时长列表。完成专注会话时，应用会追加一个时长。
- **评估字段** — 备注、「明天提醒」以及**反思**（自由文本；见 [[4.18-Reflection]]）。这些是你在评估表中输入的内容。
- **影响评分** — 你对当天工作影响力的 1–4 评分。这是生产力分数的**主要驱动**：应用对影响的权重高于原始时间。
- **精力签到** — 你对自我感觉的 1–3 评分（例如筋疲力尽 / 还行 / 良好）。这进入**可持续性**分数，使应用能区分「高效但在倦怠」与「高效且可持续」。
- **工作与任务计数器** — 该日的总工作分钟（或从 worklog 推导）、已完成任务数与计划任务数（当应用记录它们时）。

因此「应用为一天记住什么」是：日期、专注会话、备注/提醒/反思、影响、精力，以及工作/任务合计。你看到的其他一切（分数、平均值、趋势、图表）都是在打开相关视图时从这些存储数据加上 worklog 与任务数据**计算**得出的。

### 按需计算

应用**不**存储这些；需要时才计算：

- **汇总指标（简单指标）** — 对所选**日期范围**与**上下文**（见下文），应用计算：总花费时间、总休息时间与休息次数、任务计数（已完成、总计、子任务等）、范围内工作天数，以及**平均值**（例如每日平均时间、每任务平均时间、每日平均休息）。这些从 worklog、休息数据与任务列表推导。
- **生产力分数** — 一天（或一段时期的平均）的 0–100 风格分数，来自：**影响评分**（主要权重）、**专注分钟**（来自专注会话）与**总工作分钟**。因此分数更多反映「工作多有价值？」而非「多少小时？」
- **可持续性分数** — 结合**专注分钟**、**总工作分钟**与你的**精力签到**的分数。有助于区分「高效且可持续」与「高效但过度」。
- **趋势指示器** — 环比比较（例如本周 vs 上周）：生产力或可持续性是上升、下降还是稳定，以及幅度多大。
- **生产力分解** — 一系列日期中每天的分数、影响、专注分钟、总分钟与精力条目，用于表格与图表。
- **图表数据** — 生产力与可持续性分数随时间的折线图（以及其他系列，如专注会话或简单计数器数据）。底层数字从显示范围内的持久化指标与 worklog 计算。

因此当你打开**指标视图**或**评估表**时，应用加载存储的每日记录，然后为你查看的范围与上下文计算分数与汇总。全局图表系列显示在 Today 指标视图中。

## 持久化 vs 计算：为何重要

- **持久化** — 存储在你的数据中（若使用同步则同步）。你可以编辑或添加（例如影响、精力、反思）；应用仅在你工作时追加专注会话并更新工作/任务计数器。这是该日的「真实来源」。
- **计算** — 不作为单独数字存储。若你更改持久化值（例如影响）或添加更多专注会话，下次打开指标视图或评估表时，分数与趋势会**重新计算**。因此你始终看到与当前存储数据匹配的分数与图表。

这种拆分使存储简单（每天一条记录、固定字段集），同时仍提供丰富的汇总与趋势。

## 应用的哪些部分使用这些指标？

- **指标视图** — 显示当前工作上下文的**汇总指标表**（花费时间、估算时间、已完成/已创建任务、工作天数、每日平均时间、每任务平均时间、休息等）。当上下文是**今天**（「所有任务」/ today 视图）时，表格反映配置范围内所有任务的指标；当上下文是**项目**时，表格仅反映该项目的任务与 worklog。Today 指标视图还可显示生产力与可持续性分数、专注会话以及简单计数器数据随时间的全局**折线图**。
- **评估表** — 对**单日**显示并编辑持久化字段（备注、反思、影响、精力、明天提醒），并根据专注会话、工作分钟、影响与精力**计算**该日的**生产力分数**与**可持续性分数**。因此评估表既是你**输入**每日数据之处，也是**查看**该日分数之处。
- **分享 / 摘要** — 当你使用分享或「工作摘要」功能时，应用从**汇总指标**（以及可选的当前项目或今天上下文）构建摘要，因此分享文本反映你在该上下文与范围内指标表中看到的相同数字。
- **图表** — 折线图（例如过去 N 天的生产力与可持续性）显示在 Today 指标视图中，并由**计算**的分解与分数数据绘制；它们没有单独存储的「图表」对象。

因此：**持久化数据**在评估表中编辑与查看（专注会话自动添加）；**计算**的汇总与分数显示在指标视图、评估表与分享摘要中，而全局趋势与图表显示在 Today 指标视图中。

## 上下文如何影响指标

**汇总指标表**（花费时间、任务计数、平均值等）是**上下文敏感**的：

- **今天 / 所有任务** — 应用使用**所有任务**与完整 worklog 计算合计与平均值。因此你看到所选范围内的「一切」。
- **项目** — 应用仅使用**当前项目中的任务**以及该项目的 worklog。因此你看到项目特定的合计与平均值。

**评估表**与**每日分数**始终是**按日**的（一次一个日期）。生产力与可持续性的**趋势**与**图表**从存储的每日记录与 worklog 在**日期范围**（例如过去 7 或 30 天）上计算；它们不受项目限制——使用全局每日指标记录与 worklog，并出现在 Today 指标视图中。

## 小结

- **每日持久化：** 日期、专注会话、备注、明天提醒、反思、影响（1–4）、精力（1–3）、总工作分钟、已完成/计划任务计数。
- **按需计算：** 汇总指标（花费时间、休息、任务计数、范围内平均值）、生产力分数、可持续性分数、趋势指示器、生产力分解与图表数据。
- **生产力分数**强调**影响**；**可持续性分数**使用专注时间、总工作与**精力签到**。
- **你在何处看到它们：** 评估表（每日输入与分数）、指标视图（按上下文的汇总表，Today 中的全局图表）、分享摘要（当前上下文的汇总）。
