# Web 应用与桌面版对比

本参考列举 Web 应用相对桌面（Electron）应用的功能差异与限制。多数限制源于浏览器安全机制（CORS、CSP、沙箱），而非有意移除功能。

## Web 应用中不可用或受限的功能

### 插件系统

需要 Node.js 执行（提升权限）的插件在 Web 版中禁用。加载此类插件时，应用会显示禁用占位符，并提示该插件需要桌面版。

任一平台上，插件相对宿主应用都没有强沙箱隔离。安装第三方代码前请参阅 [[2.21-Manage-Plugins]]。

### 日历集成

可通过 `isDisabledForWebApp` 标志在 Web 应用或 Android 应用中禁用日历提供方，以避免 CORS 与 WebView 失败。设置该标志且应用在浏览器或 Android WebView 中运行时，日历事件请求会返回空结果，而不发起 HTTP 请求。UI 会显示醒目警告：日历集成在浏览器或 Android 应用中很可能无法工作，并建议下载桌面版。

### 本地文件系统

- **自动备份到文件系统：** 仅 Electron（桌面）与 Android 可用；Web 浏览器中不可用。
- **本地文件同步：** Web 应用无法同步到本地或网络文件夹；该同步提供方在浏览器中不可用。

### 时间跟踪

在 Web 版中，时间跟踪仅在应用打开时有效。浏览器中的空闲时间跟踪需要安装 Super Productivity Chrome Extension。没有扩展则无空闲检测，因此忘记的计时器会一直运行；跟踪任务时，浏览器标签页标题会显示该任务今天已记录的时间及其名称（例如 `25m - Write report`），从而在后台标签页也能看到正在运行的计时器。

### 应用更新

Web 应用通过其 service worker 自行更新，并在部署新版本时提示重新加载。桌面应用则每天向 GitHub releases API 检查一次，并显示可关闭的通知（含下载页链接）（可通过杂项设置「自动检查新版本」配置；Microsoft Store、Mac App Store 或 Snap 构建中无此项，它们通过各自商店更新）。

### URL Scheme 操作

`create-task`/`complete-task` URL scheme 操作（见 [[3.01-API]]）依赖应用已注册的自定义 URL scheme，Electron 以及 Capacitor 的 iOS 与 Android 构建具备该能力。Web（浏览器）构建中不可用。

## 与浏览器相关的限制

### CORS（跨源资源共享）

由于 CORS，WebDAV 同步与日历集成在浏览器中很可能失败。应用会检测与 CORS 相关的失败，并可显示本地化消息，建议用户检查服务器配置。桌面与移动（iOS/Android）应用通过原生 HTTP 层发起这些请求，不受浏览器 CORS 约束；Web 应用则受约束。因此 CalDAV 日历同步（例如与 iCloud）在桌面与移动应用中可用，但在 Web 应用中通常失败，因为服务器未发送所需的 CORS 头。

### WebCrypto API

Web 应用依赖现代浏览器对以下能力的支持：

- **Dropbox PKCE 认证：** 需要 `window.crypto.getRandomValues` 与 `window.crypto.subtle.digest`。
- **安全上下文：** WebCrypto（例如 `crypto.subtle`）仅在安全上下文（HTTPS）中可用。当 WebCrypto 不可用或通过非 HTTPS 运行时，应用会显示警告。

### 多标签页实例防护

Web 版使用 BroadcastChannel 防止多个标签页同时运行应用。若另一标签页已打开应用，新标签页会显示阻止消息，要求用户关闭其中一个标签页。

## 存储、内存与性能

### 浏览器存储持久化

Web 应用会向浏览器请求持久化存储。若请求被拒绝，用户会看到数据可能丢失的警告。拒绝通过 snack 通知呈现。

### 存储配额监控

应用使用 Storage API 估算用量与配额。当可用空间降至 333 MiB 或更低时，会提醒用户磁盘空间不足，应用可能受影响。

### IndexedDB 配额超出

当 IndexedDB 配额超出时，应用会触发紧急压缩，缩短保留期（24 小时而非 7 天），并使用断路器避免无限重试循环。

### Service Worker

Web 应用注册 Service Worker 以进行离线缓存（PWA）。Electron 与 Android 上禁用。后台行为受限于浏览器 Service Worker API 所允许的范围。

## 文件大小与上传限制（同步）

这些限制由同步服务器强制执行；它们影响进行同步的 Web 用户：

- **操作载荷：** 最大 20 MB。
- **压缩后的操作：** 最大 10 MB。
- **快照：** 压缩后 30 MB，解压后 100 MB。
- **WebDAV：** XML 响应最大 10 MB；文件内容最大 100 MB。

## 离线与后台处理

### 后台节流

桌面应用会禁用其窗口的后台节流。Web 应用受浏览器后台标签页节流影响，当标签页在后台时可能影响计时器精度与后台任务执行。

### 离线支持

Web 应用使用 Service Worker（生产构建）缓存资源以提供有限的离线使用。完整离线行为比桌面与 Android 更受限。网络不可用时应用会显示离线横幅。

## 插件与集成限制（Web）

### Iframe 中的插件 API

Iframe 插件会收到注入到 `index.html` 的经过滤的 `window.PluginAPI` 对象。
Iframe 可使用注入的任务/项目/标签 API、对话框与通知 API、导航辅助、持久化辅助、注册辅助、计数器以及 action 分发。未注入到 iframe 的 API 不可用，即使它们存在于宿主侧插件桥接上。

当桌面应用授予插件 `nodeExecution` 权限时，iframe 插件的 `executeNodeScript()` 会通过宿主桥接代理。内置与上传的插件都可申请该权限。上传的插件会收到原生警告：其身份未经验证，授予访问权限即允许完整机器访问。

### Iframe 边界

Iframe 插件使用受支持的桥接，但这不是安全边界：

- Iframe 包含 `allow-same-origin`，这对打包的桌面 UI 是必需的。
- 同源 iframe 代码可直接访问父页面。经过滤的 Plugin API `postMessage` 桥接是预期接口，而非强制隔离。
- 便携式 iframe 插件的内联 CSS、JavaScript 与小型资源在 `index.html` 中。上传插件 ZIP 中的任意额外文件不会提供给 iframe；外部 URL 取决于应用/运行时 CSP。

### 用于集成的 Chrome 扩展

Web 版中的 Jira 集成与空闲时间跟踪需要安装 Super Productivity Chrome Extension。

对于已配置适当 CORS 头的自托管 Jira 实例，可绕过扩展要求：在 Jira 高级设置中启用 **直接从浏览器获取 Jira（绕过扩展）**。启用后，应用从浏览器直接发送 API 请求，而不再经扩展路由。此选项在桌面应用或 Android 上无效。

若 Jira API 的可达主机与公开 issue 链接不同（例如内部 API 端点与公开 URL），请将 **Jira 链接的备用主机** 设为公开主机。该值仅用于在任务详情中构造浏览器 URL，不用于 API 调用。

## Web 应用中不可用的原生功能

Web 版不具备：

- 原生文件系统访问（打开/保存对话框、自动备份到磁盘）。
- 操作系统级通知（改为使用 Web Notifications API）。
- 窗口管理（最小化到托盘、全局显示/隐藏、自定义标题栏）。
- 系统托盘集成。
- 全局键盘快捷键（仅有页内快捷键；桌面可注册系统级快捷键）。

与这些功能绑定的某些 UI 元素会通过特定于平台的 CSS 或逻辑在 Web 构建中隐藏。

## 特定于平台的可用性

### 捐赠与贡献链接

Support Us 页面以及可导向 GitHub Sponsors 的链接在原生 iOS 与 macOS 桌面构建中不可用。它们在 Web 应用、原生 Android、Windows 桌面与 Linux 桌面构建中仍可用。

## 已记录的错误情况（Web）

- **CORS 错误：** WebDAV（及类似）同步可能报告 CORS 失败，并附带建议检查服务器配置的本地化消息。
- **WebCrypto 不可用：** 当 WebCrypto 缺失或不在安全上下文中时，Dropbox OAuth 及其他依赖加密的功能会显示警告。
- **存储持久化被拒绝：** 浏览器拒绝持久化存储请求时，会通过 snack 通知警告。
- **配额超出：** 应用处理多种配额超出变体（例如 Firefox `NS_ERROR_DOM_QUOTA_REACHED`、Safari 代码 22）并触发紧急压缩。

## 说明

- 项目 README 将 Web 版描述为「略有限制」，并建议使用桌面版以获得完整功能，尤其是日历、文件系统访问与插件支持。
- Android 应用提供「无连接模式」以完全离线使用；Web 应用无对等功能。
- 浏览器中的某些集成功能依赖 Chrome 扩展以绕过安全限制。

安装与下载选项见 [[2.01-Downloads and Install]]。同步后端与限制见 [[2.09-Configure-Sync-Backend]]。
