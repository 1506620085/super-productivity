# 构建 Android 应用

如何构建 Super Productivity 的 Android 应用。

Android 应用位于本仓库的 `android/` 目录，支持
**Connectivity-Free Mode**（离线优先）与 **Online-Only Mode**（兼容模式）。

## 在哪里查看说明

完整的构建与配置步骤见：

**[android/README.md](https://github.com/super-productivity/super-productivity/blob/master/android/README.md)**（本仓库中：`android/README.md`）

该 README 涵盖：

- 选择启动模式（Connectivity-Free 与 Online-Only）
- 在 `app_config.properties` 中设置 `LAUNCH_MODE`
- 分步构建指南：
  - [Connectivity-Free Mode](https://github.com/super-productivity/super-productivity/blob/master/android/README_OFFLINE.md)（推荐）
  - [Online-Only Mode](https://github.com/super-productivity/super-productivity/blob/master/android/README_ONLINE.md)
