# 第一步

欢迎！本 Quickstart 助你快速上手 Super Productivity：先试用 Web 应用，添加并管理任务、使用时间跟踪器，再了解如何安装桌面或移动应用，以及接下来去哪里（同步、备份与其他资源）。

---

## 第 1 部分：快速导览（Web 应用）

打开 [Web App](https://app.super-productivity.com/)。它不包含全部桌面功能，但足以入门。首次打开会有交互式导览；本文与之紧密对应。

[[assets/1.01-First-Steps-welcome.png]]

**添加任务：** 使用右上角的 “+” 按钮或 `Shift+A`。可按需添加任意数量任务。支持简写语法（与许多其他任务管理器类似）。完成后按 Escape，或点击任务浮层外区域。

[[assets/1.01-First-Steps-create-task.png]]

[[assets/1.01-First-Steps-finish-task-creation.png]]

**时间跟踪：** Super Productivity 将时间跟踪作为核心功能。之后可以增删已用时间。可从应用内任意位置启动与停止计时器。

[[assets/1.01-First-Steps-start-time-tracking.png]]

[[assets/1.01-First-Steps-pause-time-tracking.png]]

**任务详情：** 打开任意任务的侧栏以编辑其详情。

[[assets/1.01-First-Steps-task-details.png]]

[[assets/1.01-First-Steps-task-details-1.png]]

**删除任务：** 右键任务并使用底部的 “Delete Task”，或选中任务后按 Backspace。

[[assets/1.01-First-Steps-delete-task.png]]

继续应用内导览以了解 Projects 与 Issues。打开 **Settings**。

[[assets/1.01-First-Steps-settings-sync-1.png]]

起初 Web 应用仅限于单台电脑上的浏览器。若 Super Productivity 适合你，通常会想配置 **Sync**，以便可靠保存数据——即便只用一台电脑也如此。同步可先跳过，稍后再设（见 [[1.02-Configure-Data-Synchronization]]）。

[[assets/1.01-First-Steps-settings-sync-2.png]]

**结束一天：** 在主 Today 视图有 “Finish Day” 按钮。它会将已完成任务移入归档，并显示日终报告：已跟踪时间对比预估，以及主观评分（工作时的感受）。

[[assets/1.01-First-Steps-finish-day-0.png]]

[[assets/1.01-First-Steps-finish-day-1.png]]

[[assets/1.01-First-Steps-finish-day-2.png]]

以上就是基础。Super Productivity 支持多种工作方式；目前先专注添加任务与使用时间跟踪器。准备好后再探索更多选项。
