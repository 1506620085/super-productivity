# 贡献翻译

如何为 Super Productivity 添加或更新翻译。

翻译是 `src/assets/i18n/` 中的 JSON 文件。英文（`en.json`）是源语言与回退语言：缺失或为空的值会显示英文文本。

## 步骤

1. 在 `src/assets/i18n/en.json` 中添加或更新源字符串。
2. **不要**直接编辑其他语言的 locale 文件。这些文件由翻译脚本管理，直接编辑可能被覆盖。
3. 在本地运行应用（[[2.11-Run-the-Development-Server]]）并检查 UI。
4. 若需传播 locale 文件，或提取并合并翻译进行中的文件，请遵循 `docs/i18n-script-usage.md`。
5. 提交 pull request。

## 格式与约定

- 保持现有的嵌套 JSON 结构与 SCREAMING_SNAKE_CASE 键名。
- 优先使用简短、清晰的文本（UI 空间有限）。
- 直接编辑 `en.json`；其他所有语言使用脚本工作流。

## 翻译工具

若要查找缺失的键并保持文件同步，请使用仓库中描述的脚本：

**[docs/i18n-script-usage.md](https://github.com/super-productivity/super-productivity/blob/master/docs/i18n-script-usage.md)**（以及 `tools/add-missing-i18n-variables.js`）。

完整贡献者说明：[docs/TRANSLATING.md](https://github.com/super-productivity/super-productivity/blob/master/docs/TRANSLATING.md)。
