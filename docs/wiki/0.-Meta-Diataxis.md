# Wiki 文档框架

本 Wiki 基于 [Diátaxis](https://diataxis.fr/) 文档框架进行组织。更偏实践的落地说明见 [Openedx](https://docs.openedx.org/en/open-release-sumac.master/documentors/concepts/content_types.html#open-edx-diataxis-guide)。

> [Diátaxis 框架](https://diataxis.fr/) 是一种提升技术文档质量的方法，并形成系统性组织。Diátaxis 识别出四种文档模式：
>
> - [Quickstart](https://docs.openedx.org/en/open-release-sumac.master/documentors/concepts/content_types.html#quickstart)：教你如何做某件事
> - [How-To Guide](https://docs.openedx.org/en/open-release-sumac.master/documentors/concepts/content_types.html#id2)：告诉你为解决某个问题或完成某项任务该做什么
> - [Reference](https://docs.openedx.org/en/open-release-sumac.master/documentors/concepts/content_types.html#reference)：事实性、相对静态的信息
> - [Concepts](https://docs.openedx.org/en/open-release-sumac.master/documentors/concepts/content_types.html#concept)：解释某事物的理论、背景、目的和/或用途

本框架在 Wiki 中的具体实现见 [[0.00-Wiki-Structure-and-Organization]]。
