# 主题

Super Productivity 包含内置主题，并可安装本地 CSS 主题文件。主题仅改变外观；不会更改或同步任务数据。

## 内置主题

应用随附以下主题，可在 **设置 → 常规 → 主题** 下选择：

- Default
- Arc
- Catppuccin Mocha
- Cybr (Cyberpunk)
- Dark Base
- Dracula
- Everforest
- Glass
- Lines
- Liquid Glass
- Nord Polar Night
- Nord Snow Storm
- Plainspace
- Rainbow
- Velvet
- Zen

你还可以用自定义的主色、强调色与警告色为个别项目与标签着色。

项目、标签、Today 与收件箱主题设置还可为浅色与深色模式使用不同的背景图片。当至少设置了一张背景图时，会显示 **加深/变亮背景图以获得更好对比度** 滑块与 **模糊背景图** 滑块。模糊滑块默认值为 `0px`。当至少有一种模式没有背景图、仍使用应用的着色背景时，会显示 **禁用彩色背景色调** 设置。

## 自定义 CSS 主题

- 选择 **安装主题…** 并选择一个 `.css` 文件。已安装主题本地存储在 IndexedDB 中，并与内置主题出现在同一主题列表中。
- 主题应至少定义 `--surface-1`、`--surface-2`、`--ink` 与 `--ink-on-channel`。缺失的令牌会产生警告并继承应用默认值。
- 通过设置安装的主题无法加载远程或打包资源。远程 URL、相对 URL、`data:` URL、`@import`、`src()` 以及大于 500 KB 的文件会被拒绝。
- 仅安装来自你信任来源的主题。CSS 无法执行脚本，但可以隐藏或在视觉上重新排列信息。

Electron 还保留用户数据文件夹中遗留的可选 **`styles.css`** 文件。它是未经验证的受信任本地 CSS，可以加载资源，因此请仅使用你能控制的 CSS。其位置见 [[3.06-User-Data]]。更推荐使用应用内安装器，因为已安装主题可在设置中选择与移除。
