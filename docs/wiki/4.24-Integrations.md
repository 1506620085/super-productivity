# 集成

Super Productivity 提供两类主要集成：**议题提供方（Issue Providers）**（用于从外部项目管理或议题追踪系统引入任务）与**同步提供方（Sync Providers）**（用于备份并在多设备间同步数据）。两者均为可选。了解各自作用、有哪些提供方，以及如何融入工作流，有助于你决定是否使用以及如何使用。

关于议题集成的逐步设置与日常使用，见 [[2.07-Manage-Task-Integrations]]。关于议题提供方能力的详细对比，见 [[3.07-Issue-Integration-Comparison]]；关于同步提供方，见 [[3.08-Sync-Integration-Comparison]]。关于数据存储位置、同步与备份如何工作，以及技术细节，见 [[3.06-User-Data]] 与 [[4.23-Managing-Your-Data]]。

## 两类集成

### 议题提供方

**议题提供方**将应用连接到外部系统（Jira、GitHub、GitLab 等），使你可以：

- 在这些系统中搜索议题（缺陷、故事、工单）。
- 一键将其添加为 Super Productivity 中的任务。
- 使任务标题、状态及其他详情与外部系统保持同步。
- 可选地回传工时日志或状态更新（在提供方支持时）。

每个议题提供方都有自己的配置（URL、API 令牌、过滤器）。你可以启用多个提供方，并分配到不同项目。从议题创建的任务会带有**议题集成属性**（议题 ID、提供方、指向外部条目的链接）；见 [[4.09-Task-Attributes]]。

### 同步提供方

**同步提供方**负责设备之间（或应用与备份位置之间）的**数据同步**。它们不导入议题；而是同步你已有的 Super Productivity 数据（任务、项目、时间追踪、设置等）。支持的选项包括：

- **WebDAV** — 适用于 Nextcloud、ownCloud 及其他兼容 WebDAV 的服务器。
- **Dropbox** — 使用 OAuth，可将同步文件存入 Dropbox。
- **SuperSync** — 专用同步服务器，可选端到端加密。SuperSync 非常新，仍处于 beta。
- **本地文件同步** — 仅桌面端；同步到本地或网络文件夹。

同步是本地优先且基于操作的：设备持有主副本，变更作为操作发送到远端。关于同步提供方的对比（平台、认证、加密），见 [[3.08-Sync-Integration-Comparison]]。关于冲突处理与备份行为，见 [[4.23-Managing-Your-Data]] 与 [[3.06-User-Data]]。

## 可用的议题提供方

应用支持 **11 种议题类集成**（确切列表可能因版本而异）：**Jira**、**GitHub**、**GitLab**、**Gitea**、**OpenProject**、**CalDAV**、**日历（iCal）**、**Redmine**、**Trello**、**Linear** 与 **ClickUp**。每种在议题面板中都有显示名称与图标。配置按提供方进行，且常按项目（例如新议题加入哪个项目）。

**能力因提供方而异。** 有些支持完整双向同步（例如状态流转与工时提交）；有些主要用于导入与刷新议题。关于各议题提供方支持内容的对比——议题导入、状态流转、工时、评论、子任务、附件、过滤、自动导入、故事点、截止日期——见 [[3.07-Issue-Integration-Comparison]]。关于同步提供方（WebDAV、Dropbox、SuperSync、本地文件）的对比，见 [[3.08-Sync-Integration-Comparison]]。简而言之：Jira 与 OpenProject 提供最广的能力集（工时、状态工作流、故事点）；GitHub 与 GitLab 提供议题导入与评论；CalDAV 与日历（iCal）侧重日历/待办与事件；ClickUp 与 Jira 一样支持子任务。

### iCal 与 CalDAV

**日历（iCal）** 与 **CalDAV** 都与日历相关，但**使用不同的协议与数据**：

**日历（iCal）** — 使用**订阅 URL** 获取 **iCal 订阅源**（例如 `.ics`）。应用仅解析 **VEVENT** 组件（带起止时间的事件）。事件出现在日程/规划器中；事件描述成为任务备注。

- **无需登录**：只需粘贴日历 URL（例如「订阅」或「导出」链接）。
- 应用**不会**将完成状态或变更同步回服务器；若你在应用中修改事件，外部日历不会更新。
- 在 **Nextcloud** 中，请使用 **「复制订阅链接」**（或等效选项），使 URL 符合 iCal 期望的形式（例如 `https://<NC-URL>/remote.php/dav/public-calendars/<CALENDAR-ID>?export`）。此处**不要**使用「复制私人链接」——该格式用于 CalDAV。

**CalDAV** — 使用**用户名与密码**连接到 **CalDAV 服务器**（例如 Nextcloud 日历）。

- 应用仅请求 **VTODO** 组件（任务/待办）。它**不**使用 VEVENT。
- 你可以导入任务。对于已导入的 VTODO，完成状态、标题与备注可分别配置为**关闭**、**仅拉取**、**仅推送**或**双向**。这样完成状态变更可从 CalDAV 拉取、推回，或双向同步。在 Super Productivity 内创建的任务**不会**作为新的 CalDAV VTODO 上传。
- 在 **Nextcloud** 中，请使用 **「复制私人链接」**（或你的用户/日历的 CalDAV URL），例如 `https://<NC-URL>/remote.php/dav/calendars/<USER>/<CALENDAR_NAME>/`。此处**不要**使用订阅/导出链接——那是给 iCal 集成用的。

**Google 日历 OAuth 是按设备的。**「连接 Google 账户」的授权存储在本地，不包含在 Super Productivity 同步中。请在每台设备（桌面、Android 或 iOS）上分别完成 Google 日历连接流程。这是有意设计，使日历访问在设备间保持隔离。

更多细节见 [[3.07-Issue-Integration-Comparison]]。

## 实际中如何使用集成

### 设置

1. 打开**议题面板**（桌面端在右侧，移动端在底部），使用「+」标签页查看可用的议题提供方。
2. 添加并配置提供方：在该提供方的表单中输入 URL、API 令牌及任意过滤器（例如 JQL、经办人）。
3. 可选地设置默认项目，使新议题加入正确项目；若使用多个提供方，可通过拖放重新排序提供方标签页。

同步在别处单独配置（例如在设置中）：选择同步提供方并连接你的账户或路径。

### 日常工作流

1. **搜索并添加** — 在议题面板中，在某个提供方内搜索，并一键将议题添加为任务。
2. **轮询** — 应用可通过两种方式轮询：
   - **轮询变更** — 当外部系统变更时，更新已导入的任务。
   - **自动加入待办列表** — 定期将匹配过滤器的新议题导入到项目待办列表。
3. **任务同步** — 当外部系统中的议题变更时，应用可更新关联任务并通知你。
4. **回传数据** — 对于支持此功能的提供方（例如 Jira、OpenProject），完成任务或记录时间可将工时或状态更新提交到外部系统。

### 实用选项

- **固定搜索** — 在议题面板中保存常用搜索查询，便于快速访问。
- **默认项目** — 将提供方关联到某个项目，使新议题默认落入该项目。
- **子任务** — 像 Jira 这类提供方可导入子任务并在应用中保持层级；见 [[4.11-Subtasks]]。

## 对不使用集成的用户的影响

集成是**可选的**，并设计为在不使用时**影响最小**：

1. **议题面板** — 仅在你打开它或添加提供方时显示。你可以用主添加任务栏完成一切，而从不看到议题集成。
2. **任务创建** — 你可以创建并使用「普通」任务（无议题链接），无需任何提供方。核心添加任务流程不依赖集成。
3. **界面** — 议题面板可关闭，以免界面杂乱。
4. **性能** — 当提供方禁用时，不会对其运行轮询或 API 调用，因此未使用的提供方没有后台开销。

若你只使用同步（例如 WebDAV 或 Dropbox）而不使用议题提供方，你可获得备份与跨设备同步，而没有任何议题导入功能。

## 平台与隐私说明

- **Web 与桌面** — 某些集成（例如 Jira、日历、WebDAV）在浏览器中可能受 CORS 限制。应用可能建议使用桌面版或 Chrome 扩展以获得完整功能。这不影响不使用集成的用户。
- **隐私** — 集成直接与你选择的服务通信（Jira、GitHub、你的 WebDAV 服务器等）。应用不会将你的数据发送到 Super Productivity 服务器；配置与同步数据由你掌控，并保存在你选择的存储中。

## 小结

- **议题提供方**从外部议题/项目系统（Jira、GitHub、GitLab 等）导入并同步任务；**同步提供方**在设备间同步你的应用数据（WebDAV、Dropbox、SuperSync、本地文件）。
- 两者均为可选；应用在没有任何集成时也能完整运行。
- 设置通过议题面板（议题提供方）与同步设置（同步提供方）完成。日常使用：搜索 → 添加为任务 → 可选轮询，以及在支持处进行双向更新。
- 不使用集成的用户不会看到有意义的额外开销；议题面板与轮询仅在配置后运行。
