# 历史 / History

Super Productivity 中的「历史」视图展示你在任务上记录的时间：它把每个任务的**每日耗时**整理成 年 → 月 → 周 → 日 的层级，让你查看任意日期做了什么、花了多久。历史是从任务与归档数据**生成**的，并不单独存储时间。旧的 `worklog` 与 `quick-history` 路由会打开同一个统一视图。了解条目如何构建、数据来源，以及准确性与刷新机制，有助于你用「历史」与每日摘要进行回顾、修正与导出。

关于时间如何记录在任务上（每日耗时），见 [[4.14-How-Time-Is-Logged]]。关于归档任务及其时间如何纳入，见 [[4.20-Task-Archiving]]。

## 工时记录条目表示什么

一条**工时记录条目**是工时表中**某一天**的一行：它把一个**任务**与**当天花费的时间**关联起来。构建工时表时，每个任务的每日耗时（来自任务上的「每日耗时」）会变成一条或多条条目——有日志的每一天对应一条。在展示与导出时，每条条目本质上就是「此任务、此日期、此时长」。子任务可关联到父任务，从而在列表中显示在父任务之下；应用还会跟踪某条条目是否应排除在某些恢复操作之外，但这属于内部细节。因此从你的角度看：工时表是一份按日（以及按月、按年，或按周）分组的**任务–日期–时长**行列表。

## 工时表如何从时间追踪数据生成

工时表**不是**单独的时间存储。它是从以下内容**计算**出来的：

- **活动任务** — 当前工作上下文中的任务列表，以及每个任务的**每日耗时**（与任务上显示「今天 30 分钟」或「2 小时」的同一份数据）。
- **归档任务** — 已移入归档但仍保留时间追踪数据的任务。应用会加载当前上下文的活动任务与归档任务，再据此构建工时表，从而展示**完整历史**，而非仅当前任务。

转换过程如下：

- **遍历每个任务**及其「每日耗时」映射中的每一天。
- **构建层级** — 年 → 月 → 日（或在周视图中：年 → 周 → 日）。每一天包含条目列表（该日的任务 + 时间）以及当天的**总时间**。
- **放置子任务** — 若任务有父任务，其条目会紧挨在父任务之后（或在兄弟任务之后），使列表反映层级关系。
- **使用区域设置与工作时间** — 日标签使用你的区域设置；若已配置工作起止时间，可在可用的日级行中显示。
- **汇总且不重复计算** — 只有**叶子任务**（没有子任务的任务）将其时间计入日/月/年合计。父任务自身的「每日耗时」不会再叠加到子任务时间之上，因此合计不会虚高。

因此，工时表是对任务（及归档）上同一份「每日耗时」数据的**重组视图**。当你打开「历史」（包括旧的 `worklog`/`quick-history` 路由）或每日摘要时，应用会加载相关任务（该上下文的活动任务 + 归档），执行此转换，并显示结果。

## 准确性与完整性

- **时间来源** — 每条工时记录条目都来自 **task.timeSpentOnDay**，由正常的时间追踪流程填充（任务激活时的滴答计时，每隔几分钟批量持久化）。因此工时表反映的数据与任务列表和报表相同。
- **缺失数据** — 若任务没有「每日耗时」（例如旧数据或边界情况），应用会应用默认值，使任务仍能出现：子任务可能继承父任务时间或完成日期中的第一个日期；其他任务可能使用创建或完成日期，并附带最小时长，以便显示在列表中。这样可避免本应可见的任务从工时表中丢失。
- **不重复计算** — 只有叶子任务计入日、月、年层级的汇总合计。因此你看到的「当天总时间」对应的是工作时间的单次计数。
- **时区安全** — 日期比较使用**日期字符串**（例如 YYYY-MM-DD）而非原始时钟时间，因此时区或夏令时变化不会把时间挪到错误的一天。
- **工时表何时更新** — 当你导航到「历史」（或其旧的 `worklog`/`quick-history` 路由）或每日摘要，或触发手动刷新时，工时表会**刷新**。它**不会**在你追踪时间时持续更新；你可能需要打开该视图或刷新才能看到最新记录的时间。

## 回顾、编辑与导出

- **行内时间修正** — 叶子任务行可在行内修正。应用会更新该任务在该日期的「每日耗时」值，因此修正后的时间会反映在「历史」、报表与指标中。
- **父任务行** — 父任务显示其子任务之和，且不可直接编辑，以避免重复计算。
- **导出** — 你可以从「历史」顶部的合计处导出完整工时表，或导出单个月或周。导出使用相同的任务–日期–时长数据，并可按**项目与日期范围过滤**。有一个选项可让你**排除落在所选范围之外的时间**，从而只把范围内的时间计入导出。CSV 输出使用分号，并对包含分号、引号或换行的字段安全加引。你还可以选择用于分隔同一导出字段中多个任务值的文本。当导出按单条工时记录行分组时，每行代表一个任务、日期与时长；起止时间是日级值，而非按任务会话的时间。这样你可以得到关心时段内清晰的工作切片。

## 小结

- **工时表** = 按日期组织的视图（年 → 月 → 日，或年 → 周 → 日），展示任务上的**每日耗时**。每条条目为任务 + 日期 + 时长。
- **来源** — 由当前工作上下文的**活动任务**与**归档任务**构建；没有单独的工时表存储。
- **合计** — 只有**叶子任务**计入日/月/年合计，因此不会重复计算。
- **刷新** — 打开「历史」（或其旧的 `worklog`/`quick-history` 路由）或每日摘要，或手动刷新时更新；追踪时间时非实时。
- **编辑** — 叶子任务时间可在行内修正；父任务合计只读。
- **导出** — 可导出完整历史或单个月/周；可按项目与日期范围过滤，并可选择排除范围外时间。
