# 开发插件

如何为 Super Productivity 创建并测试自定义插件。

插件可通过自定义 UI、钩子（例如任务完成时）以及对任务、项目和计数器的 API 访问来扩展应用。插件是可执行代码，且**未与应用强沙箱隔离**。仅安装或开发来自你信任的来源的插件。面向用户的信任模型见 [[2.21-Manage-Plugins]]。

## 快速步骤

1. 创建一个文件夹，至少包含：
   - `manifest.json`（id、name、version、description、manifestVersion、minSupVersion）
   - `plugin.js`（加载时运行；可注册标题栏按钮、快捷键、钩子），或
     仅使用 iframe 的插件的 `index.html`
2. 添加 `index.html`，并在 manifest 中设置 `iFrame: true` 以启用自定义 iframe UI。若所有行为都在 `index.html` 中，可省略 `plugin.js`。
3. 将文件打包为 ZIP，且 `manifest.json` 位于 ZIP 根目录。
4. 在应用中打开 **Settings** → **Plugins** → **Choose Plugin File**，选择该 ZIP。
5. 使用 DevTools（F12 或 Ctrl+Shift+I）进行调试。

## 安全

宿主侧的 `plugin.js` 代码在应用渲染进程中运行，不在安全沙箱中。
Iframe 插件以经过过滤的 API 作为预期接口，但它们与宿主同源，该接口并非严格的安全边界。
请求 `nodeExecution` 的桌面插件仅在明确的原生同意对话框之后才能运行原生代码；一旦授权，插件将获得你用户账户下的完整访问权限。

在分发插件前，请阅读完整指南中的 **Security Considerations**。

## 完整文档与示例

完整的插件指南与 API 位于仓库中：

**[docs/plugin-development.md](https://github.com/super-productivity/super-productivity/blob/master/docs/plugin-development.md)**

内容涵盖：

- Manifest 字段、插件类型（JavaScript 与 iframe）及安全

- 最佳实践与测试

仓库中的示例插件：`packages/plugin-dev/yesterday-tasks-plugin`、`procrastination-buster`、`api-test-plugin`。偏重 UI 的插件：`packages/plugin-dev/boilerplate-solid-js`。TypeScript API 类型：`packages/plugin-api/src/types.ts`。
