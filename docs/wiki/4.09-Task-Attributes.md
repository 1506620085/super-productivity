# 任务属性（Task Attributes）

任务属性是定义 Super Productivity 中任务特征、状态与关系的属性。它们之所以核心，是因为任务是应用围绕构建的主要实体：时间追踪、项目管理、调度与同步都依赖这些属性。理解属性如何运作，有助于你看清不同功能如何协同，以及为何某些操作（例如设置截止日期或添加标签）会影响你在今日视图、日程或项目列表中看到的内容。

## 核心属性 vs 可选属性

任务需要一组最少的属性才能存在并运行。除此之外，可选属性启用调度、分类、提醒及其他工作流。

### 核心属性

核心属性是基本任务功能所必需的：

- **唯一标识符** — 每个任务都有一个 ID，以便应用在列表、同步与归档中追踪它。
- **标题** — 你在列表和视图中看到的任务名称或描述。
- **项目** — 每个任务恰好属于一个项目；项目将任务链接到工作空间及其设置。参见 [[4.06-Project-View]]。
- **每日已花费时间** — 应用追踪你每天记录了多少时间，以便时间追踪与报告保持准确。
- **完成状态** — 任务是否已完成；应用用它来显示活动 vs. 已完成任务，并驱动归档。
- **子任务** — 任务可以有子任务；应用存储子任务 ID 列表，以便父任务与子任务保持关联。参见 [[4.11-Subtasks]]。
- **创建时间** — 任务何时创建，用于排序与历史记录。
- **附件** — 与任务关联的文件附件。

仅凭这些，你就可以创建任务、记录时间、完成它们，并在项目中组织它们。其他一切都是可选的。

### 可选属性

可选属性增加调度、分类与集成能力：

- **截止日期与截止时间** — 任务计划何时进行；由 [[4.04-Schedule-View]]、[[4.03-Planner-View]] 和 [[4.01-The-Today-View]] 使用。参见 [[2.05-Manage-Scheduled-Tasks]]。
- **标签** — 用于跨领域组织的类别标记。参见 [[4.07-Tag-View]]。
- **父任务** — 对于子任务，指回父任务的链接，以便应用可以显示层级并聚合时间或完成情况。参见 [[4.11-Subtasks]]。
- **提醒** — 何时收到通知；应用存储提醒设置与计划时间。
- **重复配置** — 对于重复任务，定义任务如何重复的规则。参见 [[4.13-Repeating-Tasks]]。
- **时间预估** — 用于调度与剩余工作显示的计划时长。参见 [[4.08-Time-Estimates]]。
- **笔记** — 你附加到任务的额外文本。参见 [[4.10-Task-Notes]]。
- **问题集成** — 当任务链接到外部问题（例如 Jira 或 GitHub）时，应用存储该连接以便同步并显示问题数据。参见 [[4.24-Integrations]] 和 [[2.07-Manage-Task-Integrations]]。

你可以视工作方式使用其中的无、部分或全部。任务可以从简单开始，并在你调度、打标签或添加提醒时获得可选属性。

## 工作流支持

任务属性通过以一致的方式组合，支持不同的工作流。

### 时间管理

- **时间追踪** — 每日已花费时间随你追踪而更新；应用用它计算每日合计与回顾。
- **预估** — 时间预估属性驱动日程时间线与剩余工作显示。
- **调度** — 截止日期以及（可选的）截止时间将任务放在特定日期或时刻，以便日程与今日视图可以显示工作何时计划进行。

### 组织

- **项目** — 项目属性将任务分组到工作空间中；每个任务恰好有一个项目。
- **标签** — 标签属性让你跨项目为任务贴标签，以便过滤与分组。
- **层级** — 父任务与子任务属性定义父子结构，以便你可以分解工作并查看聚合进度。

### 集成与附加功能

- **问题追踪** — 与问题相关的属性将任务连接到外部系统，以便应用可以同步并显示问题数据。
- **提醒** — 提醒属性存储你希望何时以及如何收到通知。
- **重复** — 重复配置属性定义任务如何循环出现。

### “今日”列表与截止日期

应用将“今日”视为一个特殊的基于时间的分组：任务是否出现在 [[4.01-The-Today-View]] 中由其**截止日期**决定，而不是通过为任务添加标签。你不会添加“今日”标签；你将任务的截止日期设为今天。这使调度保持一致：同一属性（截止日期）驱动规划器、日程与今日列表，因此将任务移至今日或更改其日期会在一处更新所有这些视图。

## 生命周期演变

任务属性会随任务从创建、经活跃工作、调度、完成到归档而变化。

### 创建

当你创建任务时，应用会分配核心属性：唯一 ID、标题、项目、创建时间戳、空的已花费时间、完成状态为 false，以及空的子任务与附件列表。可选属性（截止日期、标签、预估等）仅在你使用这些功能时添加。

### 活跃工作

- 时间追踪随你记录工作更新每日已花费时间。
- 你可能在细化计划时设置或更改时间预估。
- 添加子任务会更新子任务列表以及子项上的父链接；父任务的剩余时间与完成情况可由子任务推导。

### 调度

- 设置截止日期（或截止日期与时间）会添加调度属性。任务随后会出现在该日的日程与规划器中。
- 当截止日期为今天时，任务也会出现在今日视图中；应用将截止日期作为“此任务是否属于今日？”的唯一事实来源。

### 完成

- 将任务标记为完成会设置完成状态并记录完成时间。
- 父任务可根据子任务完成情况更新其聚合状态。

### 归档

当任务被归档时，核心属性会被保留，以便任务仍可识别，且历史数据（例如已花费时间）得以保存。某些可选数据（如提醒）可能在归档中被移除，以使存储数据保持精简。任务不再出现在活动列表中，但仍可用于历史与备份。参见 [[4.20-Task-Archiving]]。

属性系统的灵活性允许任务从最小状态开始，仅在你需要调度、标签或集成时增加复杂度——全部在同一数据模型内。
