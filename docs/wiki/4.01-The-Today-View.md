# 今日视图（Today View）

今日视图是你每天工作的主要场所。它显示截止日期或截止时间落在应用**逻辑今日**范围内的任务，以便你聚焦于此刻真正重要的事项。

## 显示内容

当任务仅含日期的截止日期为逻辑今日，或其具体截止时间落在逻辑今日内时，该任务会出现在此。逻辑日默认从午夜开始。你可以在 **设置（Settings）** → **全局设置（Global Settings）** → **杂项设置（Misc Settings）** → **次日开始时间（Start time of next day）** 中将该边界推迟，这在工作日延续到午夜之后时很有用。列表会在越过该配置边界时更新。安排在逻辑日较晚时段的任务，在到达其计划时间之前可能会保持隐藏。

今日视图中任务的**顺序**由你设定。当你在此重新排列任务（例如通过拖放或键盘快捷键）时，该顺序会被保存，并在你每次打开今日视图时使用。

## 与项目和标签的区别

今日视图是**基于时间**的视图。其他工作视图则是**基于分类**的：

| 方面 | 今日视图 | 项目和标签 |
| ---------------------- | --------------------------------------------------------------------- | -------------------------------------------------- |
| **显示哪些任务** | 在逻辑今日期间到期的任务 | 属于该项目或带有该标签的任务 |
| **顺序** | 你在今日视图中设定的顺序 | 你在该项目或标签中设定的顺序 |
| **更新方式** | 列表在逻辑日边界处或到期数据变更时更新 | 通过更改项目或标签来添加或移除任务 |

你不会通过打标签的方式从今日视图“添加”或“移除”任务。将任务安排在逻辑今日会使其进入今日视图；将其截止日期或截止时间改为其他逻辑日则会将其移除。

## 规划器与今日视图

当你将任务移至今日（例如通过“移至今日（Move to Today）”或将截止日期设为今天）时，它会从其所在的任何规划器日期中移除。今日视图与 [[4.03-Planner-View]] 都表示工作何时发生——今日 vs. 未来日期——因此任务要么在今日列表上，要么在某个规划器日期上，不会同时出现在两处。
