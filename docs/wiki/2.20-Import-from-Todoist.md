# 从 Todoist 导入

一次性将你的活跃 Todoist 项目、任务、子任务、标签与截止日期导入 Super Productivity。导入是**增量的**：仅创建新的项目、标签与任务，从不更改或删除现有的 Super Productivity 数据。

## 你需要准备

- 一个 Todoist 账户及其 **API token**：在 Todoist 中打开 **Settings → Integrations → Developer** 并复制 token。该 token 仅发送至 `api.todoist.com`，且永不存储。

## 步骤

1. 打开 **Settings**（侧边栏中的齿轮图标）。
2. 打开 **Sync & Backup** 标签页，找到 **Import/Export** 部分。
3. 点击 **Import from Todoist**。
4. 粘贴你的 API token，并点击 **Load preview**。
5. 查看预览：选择要导入的项目（名称已存在的项目 —— 例如来自先前运行 —— 会被标记并默认取消勾选），并可选择如何迁移 Todoist 优先级（见下方 [Priorities](#priorities)）。
6. 点击 **Import**。摘要会列出已创建的内容以及无法迁移的内容。

## 导入内容

- 活跃项目（嵌套的项目层级会被展平；Todoist Inbox 会成为名为 “Inbox (Todoist)” 的项目）
- 活跃任务与子任务（Super Productivity 嵌套两级；更深的子任务会成为其顶层任务的直接子任务）
- 任务描述与评论（写入任务备注；HTTP(S) 评论文件附件保留其链接）
- 被导入任务使用的标签（作为 tags，加在顶层任务上）
- 截止日期（含时间）以及基于分钟的时长（作为时间预估）
- 重复任务保留其下次截止日期；重复规则会写入任务备注（例如 `Repeats: every 3 days`）

## 优先级

Todoist 优先级**默认关闭**。在预览中你可以选择其一：

- **p1–p3 tags** — 为每个顶层任务添加 `p1`、`p2` 或 `p3` 标签（Todoist 默认的 p4 保持无标签）。
- **Eisenhower matrix** — 复用 Super Productivity 内置的 `urgent` / `important` 标签，使导入的任务出现在 Eisenhower Matrix 看板中：p1 → urgent + important，p2 → important，p3 → urgent，p4 → 两者皆无。由于单个 Todoist 优先级被拆分到两个轴上，此映射是合理的默认值，而非精确翻译。

优先级标签仅添加到顶层任务 —— Super Productivity 中的子任务不能持有标签。
预览会统计不会收到所选优先级标签的、已设优先级的子任务数量。

## 不会导入的内容

- 已完成的任务与任务历史
- 嵌套的项目层级与分区（项目与任务顺序会保留）
- 子任务上的标签与映射后的优先级
- 提醒、全天时长、协作者指派与附件文件
- 作为真正重复任务的重复规则 —— 重要的请通过 [[2.06-Manage-Repeating-Tasks]] 重新创建

异常长的项目名、任务标题、标签与任务备注会被缩短至
安全的导入限制。预览会报告有多少所选值受影响。

若导入中途停止（例如连接中断），请删除错误中点名的项目，
因为它可能不完整。然后重新运行导入，并选择该项目
以及其余项目。已列为已导入的项目是完整的。若要
撤销导入，删除已创建的项目即可。

重复标题警告只能检查活跃的 Super Productivity 项目。若
先前导入的项目已归档，请在重新运行导入前将其恢复或删除，
以便能够被检测到。
