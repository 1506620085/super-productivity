# 简写语法

Super Productivity 支持五种主要简写语法形式，用于快速为任务添加元数据：标签（`#`）、项目（`+`）、时间预估（`m`/`h`）、截止日期（`@`）以及硬截止日期（`!`）。截止日期形式在添加任务栏中也接受重复短语（`@every friday`、`@daily`）。这些形式在 [[3.02-Settings-and-Preferences#short-syntax]] 中控制，硬截止日期语法另有独立的可选启用设置。

## 支持的语法形式

### 标签语法（`#`）

- **符号：** `#`
- **用途：** 为任务添加标签。
- **语法：** `#<tag-name>`。`#` 前需要空格。
- **参数：** 标签名（不区分大小写）。
- **有效：** `"Task #urgent"`、`"Meeting #work #important"`。允许多个标签。
- **无效：** `"Task#urgent"`（`#` 前无空格）——整段简写语法运行不返回任何更改。若其他标记有效（例如 `"Task#urgent #other"`），则只应用有效标签，无效标记留在标题中。

### 项目语法（`+`）

- **符号：** `+`
- **用途：** 将任务分配到项目。
- **语法：** `+<project-name>`。`+` 前需要空格。
- **参数：** 项目标题或部分标题；至少 3 个字符。匹配基于前缀、不区分大小写，比较时去除空格。多个匹配时优先最短的项目标题。
- **有效：** `"Task +Important Project"`、`"Task +Project"`（部分匹配）。名称中含 `+`、`#`、`@` 等字符的项目受支持；解析器使用前瞻，因此名称内的这些字符不会结束标记。
- **无效：** `"Task+Project"`（`+` 前无空格）——不应用项目。

### 时间预估语法

- **符号：** `m`（分钟）、`h`（小时）。可选前缀 `t`。可选 `/` 以分隔已用时间与时间预估。
- **用途：** 设置已用时间和/或时间预估。
- **语法：** `[t]<number><unit>[ <number><unit>...][/ <number><unit>...]`。单位：`m`、`h`。允许小数（例如 `1.5h`）。`/` 之前：当天已用时间。`/` 之后：时间预估。支持 `1h 30m` 这类组合。
- **参数：** 已用时间（`/` 前）：例如 `30m`、`1.5h`。时间预估（`/` 后）：例如 `1h`、`90m`。可省略一侧：`30m/` 只设置已用时间；`1h` 只设置预估。
- **有效：** `"Task 10m"`、`"Task 1h/2h"`、`"Task 30m/"`、`"Task t1.5h"`、`"Task 1h 30m / 2h"`。
- **默认：** `h` = 60 分钟。

### 截止日期语法（`@`）

- **符号：** `@`
- **用途：** 为任务设置截止日期/时间。
- **语法：** `@<date-time-expression>`。`@` 与表达式之间不允许空格。
- **参数：** 基于 Chrono 的解析器所支持的日期/时间表达式（例如 `4pm`、`friday`、`tomorrow 19:00`、`2030-10-12T13:37`）。
- **有效：** `"Task @4pm"`、`"Task @friday"`、`"Task @tomorrow 19:00"`、`"Task @2030-10-12T13:37"`。
- **无效：** `"Task @ tomorrow"`（`@` 后有空格）——不应用截止日期，且表达式会从标题中剥离。两位数年份 50–99 会被纠正为当前或下一个日历年，以免 Chrono 将其解释为年份（例如日期上下文中的 `90m`）。

### 重复语法（`@every ...`、`@daily` 等）

- **符号：** `@`，与截止日期形式共用。重复短语必须紧跟在 `@` 之后。
- **用途：** 将任务创建为重复任务，等价于在添加任务栏的重复菜单中选择预设。
- **语法：** `@every <unit>`、`@every <number> <unit>`，或单独的频率词：`@daily`、`@weekly`、`@monthly`、`@yearly`、`@annually`。`every` 的单位：`day(s)`、`week(s)`、`weekday(s)`/`workday(s)`、`month(s)`、`year(s)`、星期名（`friday`、`fri`、`fridays` 等），或月中日（`15th`）。数字可置于 `day(s)`、`week(s)`、`month(s)`、`year(s)` 或星期名之前，且必须在 1 到 999 之间。可选时间可跟在后面：`@every friday 3pm`。
- **映射：** `@every friday` → 每周五（截止日期设为下一个周五）；`@every weekday` → 周一至周五；`@every 15th` → 每月 15 日（截止日期设为下一个 15 日）；`@daily 6am` → 每日并带开始时间。无锚定的词按你添加任务的那天重复：`@weekly` 按今天的星期几，`@monthly` 按今天的日号，`@yearly` 按今天的日期。若你添加的时间在今天已过，首次发生会整周期前移，使重复日保持不变——周三 10:00 添加的 `@weekly 6am` 到期日为下周三，而非明天。`@every weekday` 从不以周末开始：周五 08:00 添加的 `@every weekday 6am` 到期日为周一。
- **间隔：** `@every 2 weeks` 创建每 2 周在你添加任务那天重复的自定义重复配置；`@every 3 days` 从那天起每 3 天重复；`@every 2 fridays` 每 2 周在周五重复，从下一个周五开始。之后可在重复配置对话框中编辑间隔。间隔为 1（`@every 1 week`）与省略数字相同。不支持 `@every 2 weekdays`——隔一个工作日不是周计划——会解析为普通截止日期。
- **有效：** `"Water plants @every friday"`、`"Journal @daily 6am"`、`"Pay rent @every 15th"`、`"Review @every 2 weeks"`、`"Water plants @every 2 fridays"`。
- **范围：** 仅在添加任务栏（任务创建）中。编辑已有任务标题时，短语会解析为普通截止日期，因为无法以此方式将已有任务转为重复任务。解析出的重复会显示在重复按钮上，并可在此清除，同时从输入中移除该短语。

### 硬截止日期语法（`!`）

- **符号：** `!`
- **用途：** 为任务设置硬截止日期日期/时间。
- **默认：** 关闭。在全局简写语法设置中启用截止日期简写语法后方可使用。
- **语法：** `!<date-time-expression>`。若不在标题开头，`!` 前需要空格。
- **参数：** 基于 Chrono 的解析器所支持的日期/时间表达式（例如 `14:30`、`friday`、`next month`）。
- **有效：** `"Task !14:30"`、`"Task !friday"`、`"Task @monday !friday"`。
- **无效：** `"Done!"`（`!` 前无空格）——感叹号视为标点，不应用硬截止日期。

## 形式语法与正则模式

解析器对每种语法形式使用正则表达式。时间：可选 `t` 前缀、带 `m`/`h` 的数字与小数、可选 `/` 表示已用/预估。项目：带前瞻的 `+`，使项目名内的分隔符（`#`、`@`、类时间标记）不会终止匹配。标签：`#` 后跟字符直到特殊字符或空白。到期：`@` 后跟字符直到特殊字符。硬截止：`!` 后跟字符直到特殊字符。确切模式定义在 `short-syntax.ts` 中（例如 `SHORT_SYNTAX_TIME_REG_EX`、`SHORT_SYNTAX_PROJECT_REG_EX`、`SHORT_SYNTAX_TAGS_REG_EX`、`SHORT_SYNTAX_DUE_REG_EX`、`SHORT_SYNTAX_DEADLINE_REG_EX`）。

## 默认值与行为

- **时间单位：** `m` = 分钟，`h` = 60 分钟。
- **仅已用时间：** 例如 `30m/` 设置当天已用时间且无预估。
- **仅时间预估：** 例如 `1h` 设置预估而不设置已用时间。
- **日期解析：** 使用基于 Chrono 的自定义解析器，并对两位数年份 50–99 做年份纠正（当前/下一年）。
- **项目匹配：** 基于前缀、不区分大小写、去除空格；最短匹配的项目标题胜出。
- **标签模式：** `combine`（默认）或 `replace`；可在设置中配置。

## 简写语法支持位置

**支持：**

- 添加任务栏（用简写语法创建任务的主要位置）。
- 添加新任务时的任务创建（例如通过共享的添加任务操作）。
- 仅标题变更时的任务标题更新（会重新解析语法）。

**不支持或已禁用：**

- **关联 Issue 的任务：** 链接到外部 issue 的任务不能使用项目语法（见 [[2.07-Manage-Task-Integrations]]）。
- **禁用时：** 已禁用的简写语法形式会被忽略。硬截止日期语法有独立设置，默认关闭。
- **已归档或隐藏的项目：** 项目语法不匹配已归档或隐藏的项目。

## 解析与求值规则

1. **处理顺序：** 到期/硬截止/时间 → 项目 → 标签。
2. **标题清理：** 处理后会从任务标题中移除已解析的语法。
3. **标签创建：** 尚不存在的标签会收集到 `newTagTitles` 数组中以便创建。
4. **返回值：** `shortSyntax()` 函数返回包含任务变更（以及 `newTagTitles`、`remindAt`、`projectId`、`repeat`）的对象；若未解析到任何内容或语法已禁用，则返回 `undefined`。
5. **按钮优先于文本：** 在添加任务栏按钮中选择日期、硬截止、预估或重复时，会从输入中移除匹配的语法，与按钮的清除（`x`）相同，从而使文本不再宣传任务不会获得的值。若任务的重复来自语法，更改日期会保留重复并将其重新锚定到新日期。

## 错误处理

**格式错误的语法：**

- 无效语法会被忽略；函数可能返回 `undefined` 或只应用有效部分。
- 不抛出异常；无效标记会按情况跳过或留在标题中。
- 若某语法类型在设置中已禁用，则不处理该形式。

**边界情况：**

- 含 `+`、`#`、`@` 或类时间模式的项目名会被正确处理，以便正确解析项目标记。
- 日期表达式中的两位数年份 50–99 会纠正为当前或下一年。
- 与日期表达式同在一个标题中的时间预估标记（例如 `90m`）会分开解析，以免 Chrono 日期解析吞掉时间预估。

## 添加任务栏行为

- **切换新任务位置：** 添加任务栏中的开关控制新任务添加到列表顶部还是底部。
- **自动完成：** 添加任务栏可在输入时建议标签、项目与日期表达式。
- **行内高亮：** 检测到的简写语法（标签、项目、预估、到期/硬截止日期、重复、提取的 URL）会在输入时直接高亮，显示创建任务前哪些字符会从标题中剥离。

## 说明

- 简写语法由 `shortSyntax()` 函数处理；在无需变更时返回任务变更或 `undefined`。
- 五种语法形式由 [[3.02-Settings-and-Preferences]] 中的全局简写语法设置控制。硬截止日期语法默认关闭。
