# 标签视图（Tag View）

**标签（tag）** 是你可以添加到任务上用于跨领域分类的标记。与每个任务恰好属于一个项目不同，任务可以有**零个、一个或多个标签**。

## 标签解决什么问题？

标签解决的是项目无法解决的**跨领域分类**问题。因为每个任务恰好属于一个项目，项目提供的是**结构性组织**。标签则提供跨项目的**灵活标记**。

例如，一个任务可能属于“Backend API”项目，但被标记为 `#urgent`、`#bug` 和 `#needs-review`。这让你可以：

- **多维分类**：按项目（结构性）和按标签（跨领域）组织
- **灵活过滤**：查看所有项目中的全部“紧急”任务，或无论所属项目查看全部“缺陷”任务
- **轻量组织**：标签是简单标记——没有像项目那样的待办积压、笔记或复杂配置

## 标签 vs 项目

| 方面 | 标签 | 项目 |
| ------------------------- | ------------------------------------------------ | --------------------------------------- |
| **与任务的关系** | 每个任务零个或多个标签（可选） | 每个任务恰好一个项目（必需） |
| **用途** | 用于灵活分类的跨领域标记 | 主要的结构性组织 |
| **功能** | 用于过滤与分组的简单标签 | 待办积压、笔记、主题、集成 |

任务必须始终属于一个项目，但标签是可选的。你可以为单个任务添加多个标签，以不同方式对其进行分类。

## 多个标签

任务可以有**多个标签**。当你创建或编辑任务时，你可以：

- 在任务标题中使用 `#tagname` 语法添加多个标签（例如：`"Fix login bug #urgent #bug #backend"`）
- 在添加任务栏中通过复选框选择多个标签
- 在标签编辑对话框中添加或移除多个标签

这让你可以从多个维度对任务分类——按紧急程度、类型、领域，或任何适合你工作流的体系。

## 按标签过滤

你可以按标签过滤任务，以查看所有项目中带有特定标签的全部任务。过滤器支持：

- **标签名搜索**：输入标签名的一部分以查找匹配标签的任务（不区分大小写）
- **无标签**：过滤为仅显示没有标签的任务

当你查看某个标签时，会看到来自多个项目且带有该标签的任务。每个任务会以徽章显示其所属项目，以便你了解它属于哪个项目。

## 特殊情况：今日标签

“今日”视图使用一种特殊的**虚拟标签**模式。归属是根据任务的截止日期或截止时间，使用已配置的逻辑日边界计算得出的，而不是来自任务标签列表中的“Today”值。这使今日视图专注于基于时间的组织，而标签仍用于基于类别的组织。

有关今日视图如何运作的更多信息，请参见 [[4.01-The-Today-View]]。
