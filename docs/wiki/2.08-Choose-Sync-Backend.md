# 选择同步后端

同步会在本应用与远程位置或其他设备之间备份并同步你的完整 Super Productivity 数据（任务、项目、时间跟踪、设置、归档等）。每台设备配置**一个**同步提供方；各设备可使用不同提供方（**Sync provider** 设置不会在设备间同步）。关于提供方的详细对比，见 [[3.08-Sync-Integration-Comparison]]。关于如何配置你所选的提供方，见 [[2.09-Configure-Sync-Backend]]。

若你仅在单台设备上使用 Super Productivity，则不必使用任何同步后端。请确保已配置备份，并了解在因其他错误导致数据损坏时如何 [[2.02-Restore-Data-From-Backup]]。

## 同步正处于过渡期

应用正在迁移到新的**基于操作（operation-based）**的同步模型（以操作而非完整数据块发送变更）。**SuperSync** 是为该模型构建的后端，也是新开发的重点。其他提供方（Dropbox、Nextcloud、WebDAV、Local file）使用当前的基于文件的同步，并仍受**支持**。代码中的 “legacy” 一词指较旧的技术实现，**并非**弃用或移除——开发者已表示 WebDAV 与 Local file 在可预见的未来很可能继续可用。请选择适合你的设置与风险承受能力的选项。

## 标签含义

在 **Sync provider** 下拉框中你会看到：

- **SuperSync (Beta)** — 为基于操作的协议构建的新同步服务。积极开发中；实时同步与可选的服务端端到端加密。**Beta** 表示仍在稳定中；部分用户更倾向于在 SuperSync 退出 beta 前使用基于文件的选项。
- **Dropbox** — 通过你的 Dropbox 账户进行基于文件的同步。OAuth 登录；应用中不存储密码。广泛使用且稳定；未弃用。
- **Nextcloud** — 通过你的 Nextcloud Files WebDAV 端点进行基于文件的同步。对 Nextcloud 请使用此选项，因为应用会根据你的服务器 URL 与用户名构建 WebDAV 文件 URL。
- **WebDAV (experimental)** — 通过任何其他兼容 WebDAV 的服务器同步（例如 ownCloud 或 NAS）。标为 **experimental**，因为各提供方的 WebDAV 实现差异很大，可能无法与每台服务器都顺畅工作。该选项不会被移除。
- **Local file (experimental)** — 将同步文件保存到你机器上的某个文件夹（桌面或 Android）。标为 **experimental**，因为行为可能取决于你如何使用该文件夹（例如同时运行多个应用实例）。对许多用户来说运行良好。它**不会**被移除。

高级用户也可以自行将其他一些存储提供方暴露为 WebDAV。例如，可通过本地 rclone WebDAV 桥接使用 Proton Drive；见 [[2.19-Sync-Proton-Drive-via-rclone]]。这不是内置的 Proton Drive 提供方。

## 何时使用哪一种

- **你想要最新的同步栈，并能接受 beta** → **SuperSync**（自托管或托管）。适合需要实时同步以及可选的服务端 E2E 加密时。
- **你想要云同步且不想运行服务器** → **Dropbox**。稳定且支持良好。
- **你已在使用 Nextcloud** → **Nextcloud**。除非你特别需要自行输入完整的 WebDAV 基 URL，否则请用此选项而非通用 WebDAV。
- **你已在使用其他 WebDAV 服务器** → **WebDAV**。先试用；若能与你的服务器配合，即可使用。若不行，experimental 标签反映的是 WebDAV 兼容性因服务器而异。
- **你想要备份或同步到本地/网络文件夹（仅桌面或 Android）** → **Local file**。无需账户，无需互联网。用于单设备，或备份到外部驱动器/NAS。**不要**使用 Syncthing 或 Resilio 等工具在设备之间同步该同一文件夹——它们可能导致冲突。对于多设备同步，请改用 WebDAV、Dropbox 或 SuperSync。
- **你使用 Proton Drive 并能接受高级设置** → 使用带有本地 rclone 桥接的 **WebDAV**。见 [[2.19-Sync-Proton-Drive-via-rclone]]。这不是官方支持的内置提供方。

## 重要：Local File 与 Syncthing/Resilio

Local file 同步将数据存储在你设备上的**一个文件夹**中。应用会警告：请**不要**使用文件同步工具（例如 Syncthing、Resilio）在设备之间同步**该文件夹**——它们可能导致冲突。若要在多台设备之间同步，请使用 Nextcloud、WebDAV、Dropbox 或 SuperSync。
