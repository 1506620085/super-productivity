# 标签：吃掉那只青蛙（Eat the Frog）

为了让自己更容易着手处理真正最重要（有时也最令人生畏）的任务，有一种被称为“吃掉那只青蛙”的理念。

其思路是为你的项目规划可执行的任务，并确保为每个任务分配一个标签（A、B、C 或 D）。每个字母代表不同的行动紧迫性类别：

A：若不完成，会对项目产生严重且相当直接后果的任务。

B：重要，但若不立即完成，不会产生直接严重后果的任务。

C：做了会更好，但可以等待的任务。

D：你在等待他人输入的任务，或应尽快委派的任务，因为所需行动不取决于你。

每隔几天审视一次计划并修订任务及其优先级，是个好主意。然后，每天早晨或前一晚，只需浏览 “A” 标签并确定当天的任务即可。
