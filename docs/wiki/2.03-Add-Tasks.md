# 添加任务

本 How-To 介绍如何向列表添加新任务。关于子任务、计划安排、重复任务以及与议题关联的任务，见 [[2.04-Manage-Subtasks]]、[[2.05-Manage-Scheduled-Tasks]]、[[2.06-Manage-Repeating-Tasks]] 与 [[2.07-Manage-Task-Integrations]]。

## 打开添加任务栏

**从页眉：** 点击顶栏中的 **Add new task** 按钮（加号图标）。添加任务栏会打开，光标聚焦到输入框。

**使用键盘：** 按 **Shift+A**（「Add new task」的默认快捷键）。可在 [[3.02-Settings-and-Preferences]] → Keyboard 下更改或确认按键；见 [[3.03-Keyboard-Shortcuts]]。

## 创建任务

1. 打开添加任务栏后，在输入框中输入任务标题。占位符会显示示例：**A task title #tag @16:00 t25m**（可在标题中使用 **#tag**、**@time**、**@date** 与 **[t]time**；见下文）。
2. 按 **Enter** 或点击 **Add task** 按钮（输入框旁的加号图标）。任务会添加到当前项目或上下文（Today / 标签）。

> 你也可以通过将 `.eml` 邮件文件拖放到 **add task** 按钮（页眉中的 **+** 图标）上来创建任务。任务标题会变为 `sender: subject`。邮件的纯文本部分——包括 quoted-printable/base64 编码的正文以及带有 HTML 备选的 multipart 消息——会作为字面文本保存到任务备注；仅含 HTML 的正文及不受支持的编码会创建仅有标题的任务。

新任务会出现在列表的**顶部**或**底部**，取决于添加栏的设置（见下文「添加到顶部或底部」）。

## 标题中的短语法

输入标题时可使用：

- **#tagName** — 将任务添加到标签（例如 `#work`）。若标签不存在，可在添加任务时创建。
- **@16:00** 或 **@09:30** — 为任务设置截止时间（仅给出时间时，默认是今天）。
- **@tomorrow**、**@next week** 或某个日期 — 设置截止日期。可与时间组合（例如 **@tomorrow @14:00**）。
- **!friday**、**!next month** 或 **!14:30** — 在 Settings 中启用截止日短语法后，设置截止日期/时间（默认关闭）。
- **[t]25m** — 为任务设置预估时间。也可以在末尾加 `/` 来添加此前已花费的时间（例如 `t30m/`）。`t` 标记是可选的，即使省略，短语法仍然有效。

关于可用的短语法标签，见 [[3.04-Short-Syntax]]。
你也可以从 Help 菜单重新启动交互式 **How to: Create a task** 演练。

添加任务栏还提供操作按钮，无需输入即可设置属性：

| 按钮         | 快捷键   | 说明                 |
| ------------ | -------- | -------------------- |
| **Schedule** | `Ctrl+4` | 设置截止日期/时间    |
| **Tags**     | `Ctrl+5` | 分配标签             |
| **Estimate** | `Ctrl+6` | 设置时间预估         |
| **Repeat**   | `Ctrl+7` | 配置重复计划         |

此外，可按 **Ctrl+8** 直接打开截止日对话框，或在标题解析出截止日芯片后点击该芯片。

设置值后，对应操作按钮或芯片旁会出现 **×** 清除按钮。在 Schedule/Planner 视图中，添加栏可能显示不同选项（例如 "Plan for today"）。

### 截止日与计划安排

- **Schedule**（`Ctrl+4`）：*你计划何时处理该任务* — 将其放入每日计划。
- **Deadline**（`Ctrl+8`）：*任务必须完成的时间* — 硬性截止日期。截止日设为今天的任务会自动移入 Today 列表。

## 添加到顶部或底部

输入框旁有一个按钮，可切换新任务加入列表的**顶部**还是**底部**。工具提示显示 “Add to top (Ctrl+1)” 或 “Add to bottom (Ctrl+1)”。也可以按 **Ctrl+1**（或你配置的按键）切换。该设置适用于你接下来添加的任务。

## 添加到 Backlog 或 Today（若项目启用了 backlog）

若当前项目启用了 **Backlog**，会出现另一个按钮：**Add to backlog** / **Add to today**。它切换新任务是添加到项目的 **backlog** 还是 **today’s list**。图标与工具提示（“Add to backlog” 与 “Add to today”）显示当前模式。

## 添加已有任务或议题（搜索模式）

点击添加任务栏中的 **search** 图标（或按 **Ctrl+2**，若已配置）以切换到 **issue search** 模式。占位符会变为 “Add existing task or issues…”。你可以搜索：

- 来自 **archive** 或其他项目的任务 — 选择一项即可将其添加到当前上下文。
- 来自已配置集成（Jira、GitHub 等）的 **Issues** — 选择一项即可将其添加为关联任务。

输入以搜索，然后从列表中选择一项来添加。再次用搜索按钮或 **Ctrl+2** 关闭搜索，即可返回普通的「创建新任务」模式。

## 新任务去向

- **项目视图：** 任务添加到**当前项目**。开启 “Add to backlog” 时进入项目 backlog；否则进入主列表（或 Today，取决于上下文）。
- **Today / 标签视图：** 任务添加到**当前标签**（例如 Today）。它们也属于某个项目；若你在某项目的 Today 视图中，任务会归属该项目。
- **Schedule / Planner：** 在此处使用添加栏时，可以为特定日期（例如今天）规划任务；任务会安排到该日。

## 从 Schedule / Planner 添加任务

在 Schedule 或每日计划视图中，某天可能会出现 **Add** 按钮（加号图标与 “Add” 标签）。点击即可就地打开同一添加任务栏；任务可创建并安排到该日。创建任务后内联添加栏会关闭。
