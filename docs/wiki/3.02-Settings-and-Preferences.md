# 设置与偏好

设置界面是可用选项与默认值的权威来源。
本页记录部分从标签上看并不直观的行为；并非逐项抄录全部设置。平台差异见 [[3.05-Web-App-vs-Desktop]]。

## 全局设置

设置各标签页上方有一个搜索框。在其中输入时会同时搜索所有标签页，并在下拉列表中显示匹配项；每项会标明所属分区，若匹配到具体选项还会显示该选项的标签。选择某一结果会切换到其所在标签页、展开对应分区并滚动定位。搜索标签页名称会列出该页上的全部内容。非可折叠分区的设置——深色模式、主题、壁纸、声音、插件以及同步配置——也可被搜索到。

### 本地化

- **日期时间格式区域设置** — 控制数字日期格式以及 12/24 小时制。ISO 8601 选项使用 `YYYY-MM-DD` 与 24 小时制。选择 ISO 8601 时，Schedule、Habits 与 Planner 中的星期标签会跟随应用语言。系统默认选项遵循浏览器或操作系统的区域设置；当某区域设置的格式数据不可用时，日期会回退为英式英语（en-GB）格式。

### 杂项

- **在托盘 / 状态菜单中显示当前倒计时（仅 macOS）** — 在桌面状态菜单标题中显示活动计时器或倒计时。禁用此项且已启用当前任务显示时，标题可改为显示当前任务。
- **自动检查新版本（仅桌面，默认：开）** — 桌面应用每天向 GitHub releases API 查询是否有更新版本，并显示可关闭的通知，其中含下载页链接。不发送个人数据，不会自动安装，且每个版本最多提示一次。该设置（以及设置页脚中的手动「检查更新」链接）仅出现在没有自有更新渠道的构建中；Microsoft Store、Mac App Store 与 Snap 构建通过各自商店更新，永不自行检查。
- **启用本地 REST API（仅桌面，默认：关）** — 在 `http://127.0.0.1:3876` 启动 localhost HTTP API，供本地脚本与工具使用。除 `GET /health` 外，每个请求都必须将生成的访问令牌作为 `Authorization: Bearer <token>` 提供。令牌显示在此设置下方，可重新生成，重新生成后会立即使旧令牌失效。这对过去无需认证即可使用 API 的旧客户端是破坏性变更。

### 应用功能

#### 用户配置文件（已弃用）

用户配置文件将在下一版本中移除。更新前请保持该功能启用，并导出每个配置文件：

1. 打开右上角的配置文件按钮，选择 **管理配置文件...**。
2. 依次点击每个配置文件旁的下载图标。

无需切换配置文件——当前所在配置文件的导出会捕获其实时数据，其余则从已存储的快照导出。

若已关闭该功能，请先在 **设置 → 应用功能** 下重新打开；配置文件数据仍在。

请妥善保存导出的 JSON 文件，因其可能包含私有数据与凭据。之后导入某一文件会替换当前应用数据；不会合并配置文件。

### 任务

- **在托盘 / 状态菜单中显示当前任务（仅 macOS/Windows）** — 允许桌面托盘或状态菜单显示活动任务。在 macOS 上，启用当前倒计时设置时，倒计时优先。

### 简写语法

- **启用截止日期简写语法** — 在输入任务标题时解析 `!<deadline time>`。此选项默认关闭。

### 空闲处理

- **启用空闲时间跟踪** — 启用后，Super Productivity 会检测你是否离开电脑，并显示空闲对话框询问你做了什么。
- **最短空闲时间** — 离开多久后才显示空闲对话框。必须至少 **1 分钟**：桌面应用从不报告更短的空闲时段，因此更低的值会向上取整到约一分钟，而不会被原样遵守。空闲每 30 秒采样一次，因此对话框可能在达到阈值后最多延迟这么久才出现。
- **仅在有活动任务时显示空闲对话框** — 仅在当前正在跟踪某任务时显示空闲对话框。
- **工作会话期间抑制空闲对话框** — 启用后，专注模式工作会话运行期间不会出现空闲对话框。适合在电脑前工作但无活跃键鼠输入时（例如阅读、学习或写考试）。默认：关（需主动开启）。

## 同步与导出

### 自动备份

- **启用自动备份** — 在当前平台支持时自动创建本地备份。
- **恢复最新自动备份** — 仅 Android。在确认后恢复最新可用的自动备份，并替换当前本地数据。
- **最大备份文件数** — 仅桌面。限制 `backups/` 文件夹中保留的自动备份 JSON 文件数量；超过上限后会删除较旧文件。

## 项目、标签、Today 与收件箱设置

### 基本设置

- **启用项目待办积压（Backlog）** — 为项目添加单独的积压列表。
- **从侧边栏隐藏项目** — 从侧边栏项目列表中移除该项目。项目仍保持活动：其任务仍可出现在跨项目任务视图中，例如 Today、Planner、Schedule、Boards 与搜索。再次显示项目仍通过侧边栏可见性菜单；项目简写语法不会匹配已隐藏的项目。

### 主题

主题设置可包含浅色模式、深色模式或两者的背景图片。
当至少设置了一张背景图时，会显示背景对比度与模糊滑块。模糊滑块默认值为 `0px`。当至少有一种模式没有背景图时，会显示彩色背景色调设置。主题详情见 [[3.09-Theming]]。
