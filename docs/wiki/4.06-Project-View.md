# 项目视图（Project View）

**项目（project）** 是 Super Productivity 中组织任务的主要方式。每个任务恰好属于一个项目，使项目成为你工作的主要组织结构。

## 项目是什么

项目是自包含的工作空间。每个项目具有：

- **任务列表** — 活动任务以及可选的待办积压
- **笔记** — 项目专用笔记
- **主题设置** — 自定义颜色与外观
- **集成设置** — 与外部问题追踪器的连接（如 Jira 或 GitHub）

当你切换到项目视图时，你只会看到属于该项目的任务，以及该项目的笔记与设置。

## 项目 vs 标签

项目和标签服务于不同的组织目的：

| 方面 | 项目 | 标签 |
| ------------------------- | ---------------------------------------------------------------- | --------------------------------------------------- |
| **与任务的关系** | 每个任务恰好属于**一个**项目（必需） | 每个任务可以有**零个或多个**标签（可选） |
| **用途** | 主要组织结构 — 每个任务都有归属项目 | 用于跨领域分类的次要标签 |
| **功能** | 待办积压、笔记、主题、集成 | 用于过滤与分组的简单标签 |

任务必须始终属于一个项目。标签是可选的标记，你可以跨不同项目为任务添加，以创建跨领域类别。

## 项目功能

**待办积压（Backlog）**：项目可以有一个单独的待办积压列表，用于存放你当前未积极处理的任务。你可以在活动列表与待办积压之间移动任务。

**笔记（Notes）**：每个项目可以有自己的笔记，与任务笔记分开。

**主题（Theme）**：项目可以有自定义颜色与外观设置，以帮助你在视觉上区分它们。

**集成（Integrations）**：项目可以连接到外部问题追踪器（如 Jira、GitHub、GitLab），以同步任务并追踪工作。

## 组织项目

项目本身是**扁平的** — 没有父项目或子项目。一个项目不能包含其他项目。

不过，你可以在导航菜单中**将项目组织到文件夹中**。文件夹可以嵌套（文件夹套文件夹）以创建导航层级，但这纯粹用于组织 — 不会改变项目的运作方式或任务的存储方式。

你可以在文件夹之间移动项目，而不影响任务或任何其他项目数据。

## 隐藏项目

当项目处于活动状态但你不希望它出现在侧边栏项目列表中时，可在项目设置中启用 **从侧边栏隐藏项目（Hide project from sidebar）**，或使用侧边栏中的项目可见性菜单。

隐藏项目仅更改导航。项目仍保持活动，其任务仍可出现在跨项目任务视图中，如今日、规划器、日程、看板和搜索。项目导航辅助功能（包括项目短语法）不会匹配隐藏项目。

## 任务如何归属项目

每个任务都有项目分配。当你创建任务时，它会被分配到当前项目（若你在标签上下文中且未配置默认项目，则分配到收件箱）。你可以通过以下方式更改任务的项目：

- 将任务拖放到导航中的另一个项目
- 编辑任务并选择不同的项目

当你查看某个项目时，会看到属于它的所有任务。当你查看某个标签时，会看到来自多个项目且带有该标签的任务，每个任务会以徽章显示其所属项目。

## 完成项目

当你完成某个项目时，可将其**完成（complete）**，以使其退出活动工作流并庆祝成果。在侧边栏中右键点击该项目（或点击 `⋮` 按钮），然后选择 **完成项目（Complete project）**。

若项目仍有**未完成的任务**，系统会先询问你如何处理它们：**移至收件箱（Move to Inbox）**（默认 — 它们仍可操作）、**标记为完成（Mark as done）**，或 **取消（Cancel）**。在项目真正完成之前，会有最终确认要求你确认该操作。

完成时你会看到全屏**庆祝**界面，并附有简短摘要 — 已完成任务数、已追踪时间、工作天数，以及项目从首次工作日到完成共持续了多少天（当你不追踪时间时，基于时间的统计会被隐藏）。

已完成的项目会完全进入**休眠**状态 — 其所有数据都会保留，但不再在应用各处产生干扰。具体而言，它会：

- 从侧边栏项目列表和主可见性清单中移除
- 其任务从今日、标签、看板、来自往日、截止日期和已调度视图中隐藏
- 其重复任务被暂停 — 不再生成新实例
- 其提醒被抑制 — 不会为其任务触发通知

**查找并重新打开**已完成的项目：点击项目分区标题中的眼睛图标以打开可见性菜单，然后导航至 **已归档项目（Archived projects）**，已完成项目会以奖杯徽章及其完成日期显示。在那里使用 **重新打开（Reopen）** 操作可清除完成状态，并将项目连同所有任务、重复配置和提醒一起带回侧边栏。
