# 键盘快捷键

Super Productivity 支持丰富的键盘快捷键系统。快捷键按功能分组，大多数可在 [[3.02-Settings-and-Preferences]] 中由用户配置。

## 功能分组

可配置快捷键属于以下类别：

- **全局（系统级）：** `globalShowHide`、`globalToggleTaskStart`、`globalAddNote`、`globalAddTask`。仅在 Electron/桌面构建中可用。
- **导航：** `goToFocusMode`、`goToWorkView`、`goToScheduledView`、`goToTimeline`、`goToSettings`。
- **任务管理：** `taskToggleDone`、`taskAddSubTask`、`taskSchedule`、`taskDelete`、`taskEditTitle`、移动/选择任务等操作。
- **UI 面板：** `toggleIssuePanel`、`toggleBacklog`、`toggleTaskViewCustomizerPanel`、`addNewTask`、`addNewProject`、`addNewNote`、`focusSideNav`、`openProjectNotes`、`showSearchBar`、`triggerSync`、`showHelp`、缩放。

项目 README（键盘快捷键章节）列出了部分最常用的默认快捷键。

## 全局快捷键

这些快捷键在应用内处处可用。

- `Shift`+`A`：打开添加任务栏
- `Shift`+`P`：打开创建项目对话框
- `Alt`+`N`：添加新笔记
- `Shift+D`：聚焦侧边栏导航
- `Shift+N`：显示/隐藏笔记
- `C`：切换筛选/分组/排序面板
- `P`：显示/隐藏 Issue 面板
- `Shift`+`F`：显示搜索栏
- `B`：显示/隐藏任务积压（Backlog）
- `W`：转到工作视图并聚焦第一个任务
- `F`：进入专注模式
- `Shift`+`T`：转到 Today
- `Shift`+`S`：转到 Schedule
- `<无默认绑定>`：转到设置
- `Ctrl`+`=`：放大（桌面/Firefox/Chrome）
- `Ctrl`+`-`：缩小（桌面/Firefox/Chrome）
- `Ctrl`+`0`（零）：默认缩放（桌面/Firefox/Chrome）
- `Ctrl`+`S`：触发同步（若已配置）
- `?`：显示键盘快捷键速查表（通常按 `Shift`+`/` 输入）

速查表会列出你当前的快捷键，包括插件快捷键，因此能反映你在 [[3.02-Settings-and-Preferences]] 中改过的绑定。保持默认 `?` 时，该快捷键匹配的是 `?` 字符本身，因此在 `?` 位于不同物理键上的布局中也能工作。与其他快捷键一样，可在键盘设置中重新绑定或移除。

搜索栏默认搜索未完成任务。在搜索视图中启用 **包含已完成与已归档任务** 可包含较旧的已完成结果。

### 桌面窗口（不可配置）

- `F11`：切换全屏模式。仅在 Electron/桌面构建中可用。

### 添加任务栏（添加栏输入框聚焦时）

- `Ctrl+1`：切换 issue 搜索模式
- `Ctrl+2`：切换笔记字段
- `Ctrl+3`：切换添加到列表顶部 / 底部
- `Ctrl+4`：打开项目选择器
- `Ctrl+5`：打开排程对话框（设置截止日期/时间）
- `Ctrl+6`：打开标签选择器
- `Ctrl+7`：打开预估选择器
- `Ctrl+8`：打开重复设置
- `Ctrl+9`：打开截止日期（deadline）对话框（设置硬截止日期）
- `Ctrl+Enter`：显示笔记字段（或在笔记聚焦时添加任务）

### 任务

以下快捷键作用于当前选中的任务（通过 Tab 或鼠标选中）。

- `<无默认绑定>`：编辑标题
- `I`：显示/隐藏额外任务信息
- `N`：在任务面板中打开笔记/清单
- `T`：编辑预估 / 已用时间
- `S`：为当前聚焦任务打开排程对话框
- `Shift`+`S`：为当前聚焦任务打开截止日期（deadline）对话框
- `D`：将当前聚焦任务标为完成
- `A`：为当前聚焦任务添加子任务
- `L`：附加文件或链接
- `Enter`：编辑当前聚焦任务标题
- `Backspace`：删除当前聚焦任务
- `E`：打开将任务移动到项目的菜单
- `Q`：打开任务上下文菜单
- `K`：选择上一个任务
- `J`：选择下一个任务
- `Ctrl`+`Shift`+`ArrowUp`：将当前聚焦任务在列表中上移
- `Ctrl`+`Shift`+`ArrowDown`：将当前聚焦任务在列表中下移
- `Ctrl`+`Alt`+`ArrowUp`：将当前聚焦任务移到顶部
- `Ctrl`+`Alt`+`ArrowDown`：将当前聚焦任务移到底部
- `Shift`+`B`：将任务移到任务积压（Backlog）
- `Shift`+`T`：将任务移到今日任务列表
- `<无默认绑定>`：展开子任务
- `<无默认绑定>`：折叠子任务
- `Y`：切换对当前聚焦任务的时间跟踪

#### 不可配置

- `方向键`：在任务列表中导航
- 在空的或仅空白的添加子任务输入框中，`ArrowUp` 聚焦前一个子任务或父任务，`ArrowDown` 在可用时聚焦下一个任务。在列表末尾时，焦点停留在最近的任务行或控件上。
- `ArrowRight`：为当前聚焦任务打开额外信息面板
- `Ctrl`+`C` / `Cmd`+`C`：当焦点在任务上、未选中文本且不在输入框内时，复制当前聚焦任务的标题

## 可折叠分组

以下快捷键在焦点位于可折叠分组标题时适用（例如工作视图中的任务分组：来自前几日、Today、Done、Recurring 等）。

- `ArrowLeft`：折叠当前聚焦的分组
- `ArrowRight`：展开当前聚焦的分组
- `Shift`+`ArrowLeft`：折叠全部分组
- `Shift`+`ArrowRight`：展开全部分组
- `Enter` 或 `Space`：切换当前聚焦的分组

这些快捷键**不可配置**，在分组标题上始终可用。

## 平台差异

**仅 Electron/桌面：**

- 全局快捷键（`globalShowHide`、`globalToggleTaskStart`、`globalAddNote`、`globalAddTask`）在应用运行时于系统级生效。
- 窗口缩放控制（`zoomIn`、`zoomOut`、`zoomDefault`）仅桌面可用。
- `F11` 切换主窗口全屏模式。
- `Cmd+W`（仅 macOS）隐藏主窗口；应用继续运行，点击 Dock 图标可恢复窗口。此快捷键不可配置。

**Linux（Wayland）：**

- Electron 内置的全局快捷键往往无法注册，因为 Wayland 刻意将全局热键留给合成器。请改为将合成器按键绑定到 URL scheme（见下文）。

**Android：**

- Android 上不显示键盘设置；键盘配置 UI 被隐藏。

## Wayland 上的全局快捷键（URL scheme）

在 Wayland 上，全局热键由合成器而非应用程序拥有，因此上文的内置全局快捷键可能不会触发。Super Productivity 注册了 `superproductivity://` URL scheme，已运行的实例会处理这些 URL，因此你可以用标准的 `xdg-open` 命令将合成器按键绑定到它们（`xdg-open` 属于 `xdg-utils`，几乎所有 Linux 桌面都已具备——无需额外工具或运行时）。

可用的即发即忘操作：

| URL                                               | 等价快捷键              | 效果                                                                                                                                                                                                                                                                               |
| ------------------------------------------------- | ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `superproductivity://toggle-visibility`           | `globalShowHide`        | 显示/聚焦窗口，或隐藏它                                                                                                                                                                                                                                                    |
| `superproductivity://add-task`                    | `globalAddTask`         | 显示窗口并打开添加任务栏                                                                                                                                                                                                                                            |
| `superproductivity://add-note`                    | `globalAddNote`         | 显示窗口并打开添加笔记对话框                                                                                                                                                                                                                                         |
| `superproductivity://task-toggle-start`           | `globalToggleTaskStart` | 开始/暂停跟踪当前任务                                                                                                                                                                                                                                                |
| `superproductivity://create-task/<title>`         | —                       | 用 URL 编码的 `<title>` 创建任务（也接受 `?title=`、`?notes=`、`?projectId=`）。会去除首尾空白，且不解析简写语法。完整约定见 [[3.01-API]]。                                                                           |
| `superproductivity://complete-task?title=<title>` | —                       | 完成匹配 URL 编码 `<title>` 的那一个未完成顶层任务；`<title>` 必须是查询参数（无路径形式）。会去除首尾空白；精确匹配优先，否则为无歧义的子串匹配。完整约定见 [[3.01-API]]。 |

手动运行任意一条以测试：

```bash
xdg-open "superproductivity://toggle-visibility"
```

然后在合成器中绑定。示例：

```kdl
// Niri (config.kdl)
binds {
    Mod+Shift+S { spawn "xdg-open" "superproductivity://toggle-visibility"; }
    Mod+Shift+A { spawn "xdg-open" "superproductivity://add-task"; }
}
```

```ini
# sway / i3 (~/.config/sway/config)
bindsym $mod+Shift+s exec xdg-open "superproductivity://toggle-visibility"
bindsym $mod+Shift+a exec xdg-open "superproductivity://add-task"
```

```ini
# Hyprland (~/.config/hypr/hyprland.conf)
bind = $mainMod SHIFT, S, exec, xdg-open "superproductivity://toggle-visibility"
bind = $mainMod SHIFT, A, exec, xdg-open "superproductivity://add-task"
```

若 `xdg-open` 无法到达应用，请用 `xdg-mime query default x-scheme-handler/superproductivity` 确认桌面项已注册该 scheme（应打印 Super Productivity 的 `.desktop` 文件）。同一机制在 X11 上也可用；仅在 Wayland 上是必需的。

> **打包说明：** `.deb`/`.rpm` 包在安装时注册该 scheme。使用 **AppImage** 时必须先将其集成到桌面（例如通过 AppImageLauncher），否则不会注册 scheme。**Flatpak/Snap** 通过各自打包的桌面文件注册，因此 `xdg-mime query` 会解析到该 id，而不是普通的 `superproductivity.desktop`。

## 可配置与保留

[[3.02-Settings-and-Preferences]] 中列出的所有快捷键均可由用户配置。用户可以：

- 点击输入框并按下目标按键或组合来更改任意快捷键。
- 按 **Escape** 离开字段，或按 **Backspace** 或 **Delete** 清除已有绑定。
- 当两个操作共享同一快捷键时，UI 会发出警告。

快捷键保存在全局配置（`GlobalConfigState.keyboard`）中，并持久化到 IndexedDB；若启用同步，会跨设备同步。没有保留快捷键；每一个都可以更改或禁用。

## 依赖上下文的行为

**任务级快捷键：** 带有任务焦点的操作（例如标为完成、添加子任务、排程、删除、移动）作用于当前选中的任务。可通过键盘（Tab/方向键）或鼠标选中。[[3.02-Settings-and-Preferences]] 中的键盘帮助文本将这些描述为作用于「当前选中的任务」。

特别地，对于 **下个月（Next Month）** 快捷键，任务会被排程到**下个月的 1 号**。这可避免不同月份天数带来的问题（例如排程到 31 号，而下个月只有 30 天）。

**Schedule 周视图：** `Ctrl`+鼠标滚轮可改变周排程网格的垂直比例。该值会本地保存，供之后访问 Schedule 时使用。

**专注模式浮层：** `Escape` 关闭浮层。若专注会话或休息正在进行，会在标题栏专注按钮中继续。

**输入过滤：** 当焦点在 input、textarea 或可编辑内容元素中，或阻塞性浮层（例如对话框）打开时，应用级与任务级快捷键不会被处理。这可避免打字时误触快捷键。

## 冲突与优先级

- **输入焦点：** 当焦点在输入元素中或阻塞性浮层打开时，会跳过快捷键处理，以免打断打字。
- **上下文优先级：** 当任务当前聚焦时，任务级快捷键优先于全局快捷键。例如，若任务已聚焦，按 `Shift+S` 会打开截止日期（deadline）对话框；若无任务聚焦，则导航到 Schedule 视图。同理，`Shift+T` 会将选中任务排程到今天，否则导航到 Today 视图。
- **冲突：** 若两个操作被分配同一按键组合，配置 UI 会警告。**Escape** 离开字段，**Backspace** 或 **Delete** 清除已有分配。

## 存储与定义

**快捷键在何处定义：**

- 配置模型：`KeyboardConfig`（electron/shared-with-frontend/keyboard-config.model.ts）。
- 默认映射：`default-global-config.const.ts`（keyboard 部分）。
- 设置表单（出现哪些操作及其标签）：`keyboard-form.const.ts`。

**在何处存储与使用：**

- 保存在 `GlobalConfigState.keyboard` 中；通过全局配置系统持久化到 IndexedDB；启用同步时会同步。
- 运行时由 `ShortcutService` 处理；按键监听器在应用根部注册（例如 `AppComponent`）。

## 说明

快捷键系统在可用时使用 Keyboard API 布局映射，以便在不同键盘布局（例如 QWERTY、QWERTZ、AZERTY、Dvorak）下行为正确。会检测用户的布局，并用于将按键事件匹配到已配置的快捷键。
