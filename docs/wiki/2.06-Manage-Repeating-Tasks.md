# 管理重复任务

关于重复配置如何工作以及实例何时创建，见 [[4.13-Repeating-Tasks]]。

## 打开重复任务对话框（添加或编辑）

**从任务：** 打开任务（点击它，使右侧任务详情面板打开），选择 **Schedule**，然后在 Schedule 对话框中选择 **Repeat**。重复任务对话框会打开，标题为 **Add Recurring Task Config**（新建）或 **Edit Recurring Task Config**（已有）。重复仅适用于未关联议题的主任务（非子任务）；从 Jira 或 Git 导入的任务不能设为重复。

**从已计划列表：** 前往 **Scheduled tasks** 页面（例如通过 **Shift+S** 或 **Go to scheduled tasks** 快捷键）。在 **Recurring Tasks** 部分，每个重复任务显示为一张卡片。点击卡片（带有重复图标与重复文本的那一行）即可打开该配置的 **Edit Recurring Task Config** 对话框。

你也可以从重复任务实例，或从 Schedule / Planner 上的重复投影打开该对话框（例如点击重复图标或事件）。

## 创建新的重复任务

1. 打开一个**主任务**（非子任务、非来自议题），在任务详情面板中选择 **Schedule**，然后选择 **Repeat**。对话框标题为 **Add Recurring Task Config**。
2. 输入 **Task title**（或保留任务当前标题，通常会预填）。
3. 在 **Recurring Config** 中选择快速设置：
   - Every day
   - Every Monday through Friday
   - Every week on &lt;weekday&gt;（例如 every week on Wednesday）
   - Every month on the day &lt;date&gt;
   - Every year on &lt;day and month&gt;
   - Custom recurring config — 然后使用额外字段（见下文）。
4. 对于 **Custom**，设置：
   - Recur every — 数字（1–1000）。
   - Recur cycle — Day、Week、Month 或 Year。
   - Schedule type（仅当间隔 &gt; 1）：Fixed schedule（从开始日期起每 X）或 After completion（我完成后再过 X）。
   - Start date — 模式开始的时间（必填）。
   - 对于周周期：勾选任务应重复的工作日（Monday–Sunday）。
   - 对于月周期：选择 **Monthly pattern**。**Day of month** 使用 **Start date** 中显示的日期；first、second、third、fourth 与 last 模式还需要选择 **Weekday**。
5. 可选设置 **Tags to add**（芯片列表）。
6. 可选设置 **Scheduled start time**（例如 15:00；留空表示全天）。若设置了时间，会出现 **Remind at** — 选择何时提醒（例如开始时、提前 5 分钟）。
7. 可选设置 **Default Estimate**（时长）。**Order**（数字）控制多个重复任务同时创建时的创建顺序；见对话框中的字段说明。
8. 在高级部分：**Default notes**、**Inherit subtasks**（将最新实例的子任务复制到下一个）、若开启继承则还有 **Disable auto-updating subtasks**（当最新实例更改时不更新已继承的子任务），以及 **Don't let overdue instances pile up**（保留单个最新实例，而不是堆积错过的重复项）。最后一项对 **Every day** 预设（或等效的自定义每天周期）默认**开启**，对其他所有计划默认**关闭**；见 [[4.13-Repeating-Tasks]]。可按任务更改。
9. 点击 **Save**。之后在打开项目或应用时，会按该模式创建新实例。

## 为重复任务添加时间与提醒

1. 打开重复任务配置（任务详情面板 → **Schedule** → **Repeat**，或已计划列表 → 点击重复任务卡片）。
2. 设置 **Scheduled start time**（例如 15:00）。留空表示全天任务。
3. 设置时间后会出现 **Remind at**。选择一个选项（例如开始时、开始前 5 分钟）。
4. 点击 **Save**。

## 为实例设置默认时间预估

在重复任务对话框中，设置 **Default Estimate**（时长）。除非你按任务更改，新实例将使用此预估。点击 **Save**。

## 为重复任务配置添加标签

在对话框中，使用 **Tags to add** 添加一个或多个标签。新实例将带有这些标签。点击 **Save**。

## 在新实例中继承子任务

1. 打开重复任务配置。
2. 启用 **Inherit subtasks**。说明文字会解释：最近任务实例中的子任务将随重复任务重新创建。
3. 可选启用 **Disable auto-updating subtasks**，这样当你在最新实例上更改模板子任务时，现有实例不会自动更新。
4. 点击 **Save**。

## 编辑重复任务配置

打开配置（任务详情面板 → **Schedule** → **Repeat**，或从已计划列表的 **Recurring Tasks** 部分点击卡片）。更改 **Task title**、**Recurring Config**、**Start date**、工作日、**Scheduled start time**、**Remind at**、**Default Estimate**、**Order**、**Default notes**、标签或继承选项。点击 **Save**。

## 删除单个实例（例如「仅今天」）

1. 打开该重复任务的 **Edit Recurring Task Config** 对话框（例如从任务实例或已计划列表）。
2. 若今天（或你打开时所对应日期）的实例可移除，会出现按钮：**Remove today** 或 **Remove for &lt;date&gt;**。点击即可仅删除该实例。重复配置与其他实例保持不变。

## 删除整个重复任务（停止所有未来实例）

1. 打开 **Edit Recurring Task Config** 对话框。
2. 点击 **Remove**。这会移除重复配置。未来实例将不再创建；现有任务实例会保留，直到你另行删除。
