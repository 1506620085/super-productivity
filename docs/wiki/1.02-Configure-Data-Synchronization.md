# Quickstart：设置并配置同步集成

本 Quickstart 引导你选择同步提供方并完成配置，使 Super Productivity 数据得以备份或在设备间同步。结束时你将启用同步，并知道如何确认其正常工作，以及如何用备份保障安全。

**学习目标：** 启用同步、选择提供方、完成其配置，并验证同步可用。

整体图景（数据包含什么、同步与备份如何配合）见 [[4.23-Managing-Your-Data]]。提供方详细对比见 [[3.08-Sync-Integration-Comparison]]。

---

## 开始之前

- **单设备：** 同步为可选。可用于将数据备份到云端或本地文件夹。请确保了解如何 [[2.02-Restore-Data-From-Backup]]，以便日后需要恢复。
- **多设备：** 需要**一个**同步提供方。各设备可使用不同提供方，但通常选择一个（例如 Dropbox 或 Nextcloud）并在所有设备上使用，以便数据保持同步。

---

## 步骤 1：选择同步提供方

应用支持五种选项。按你的工作方式选择：

| 若你想要…                                                     | 选择               |
| ---------------------------------------------------------------- | -------------------- |
| 实时同步，并能接受 beta 软件                      | **SuperSync (Beta)** |
| 云同步且无需自建服务器                       | **Dropbox**          |
| 使用现有的 Nextcloud 服务器                            | **Nextcloud**        |
| 使用其他 WebDAV 服务器                                     | **WebDAV**           |
| 备份或同步到本机文件夹（仅桌面/Android） | **Local file**       |

**不要**用文件同步工具（例如 Syncthing、Resilio）在设备间同步 **Local file** 文件夹——可能导致冲突。多设备同步请改用 Nextcloud、WebDAV、Dropbox 或 SuperSync。

何时选用何种方案的完整说明：[[2.08-Choose-Sync-Backend]]。对比表与细节：[[3.08-Sync-Integration-Comparison]]。

**结果：** 你已明确将要配置的提供方。

---

## 步骤 2：打开同步设置

1. 打开 **Settings**（齿轮图标）。
2. 打开 **Sync & Backup** 标签页。
3. 在 **Sync** 分区中打开 **Enable syncing**。
4. 从下拉菜单选择你的 **Sync provider**。

表单会显示所选提供方所需的字段。具体字段与选项见 [[2.09-Configure-Sync-Backend]]。

**结果：** 已启用同步，并显示正确的配置表单。

---

## 步骤 3：填写提供方详情

按提供方填写表单。实践中你需要：

- **SuperSync：** 从服务器获取访问令牌（例如应用中的 **Open Server & Get Token**），然后粘贴。可选：在 **Advanced** 下设置自定义服务器 URL 或启用加密。
- **Dropbox：** 通过应用内链接登录；应用不存储密码。可设置 **Sync interval** 与 **Only sync manually**，并可选在 **Advanced** 下启用加密。
- **Nextcloud：** 填写 **Server URL**、**Username** 与 **App Password**。仅当登录名与用户名不同时才使用 **Login name / email (optional)**。如需可设置 **Sync Folder Path**。同步间隔与仅手动同步同样适用；加密在 **Advanced** 下。
- **WebDAV：** 填写 **Base URL**、**Username** 与 **Password**。如需可设置 **Sync Folder Path**。同步间隔与仅手动同步同样适用；加密在 **Advanced** 下。
- **Local file：** 用文件夹选择器选择 **Sync folder path**（桌面或 Android）。同步间隔与仅手动同步同样适用；加密在 **Advanced** 下。

若启用**加密**（SuperSync 或基于文件的方案），所有将同步此数据的设备须使用相同密码或密钥。丢失密钥则无法解密数据。

**结果：** 配置已保存。应用会按设定间隔自动同步（若开启 “Only sync manually”，则仅在你触发时同步）。

---

## 步骤 4：确认同步正常工作

- **自动同步：** 等待下一次同步，或在 UI 可用时手动触发。在同步状态或通知中查看是否成功。
- **第二台设备：** 在另一台设备上启用同一提供方，并登录或指向同一账户/文件夹。首次同步后数据应一致（若两侧都有数据，可能会提示选择 “use local” 或 “use remote”）。
- **仅备份（例如 Local file）：** 打开同步文件夹，确认同步文件在同步后存在且已更新。

若失败，请在 [[2.09-Configure-Sync-Backend]] 与 [[3.08-Sync-Integration-Comparison]] 中核对提供方要求（例如 Nextcloud 的用户名与登录名、WebDAV URL 格式、Web 应用的 CORS）。

**结果：** 你已验证同步会运行；如适用，数据会出现在远端或另一台设备上。

---

## 步骤 5：牢记备份与恢复

同步不能替代“知道如何恢复”。请确保在平台支持时启用自动备份，并了解如何从备份文件 [[2.02-Restore-Data-From-Backup]]。备份与同步数据存放位置：[[3.06-User-Data]] 与 [[4.23-Managing-Your-Data]]。

**结果：** 同步与必要时的恢复路径均已就绪。
