# 配置同步后端

关于如何选择提供方，见 [[2.08-Choose-Sync-Backend]]。关于数据与备份的存放位置，见 [[3.06-User-Data]] 与 [[4.23-Managing-Your-Data]]。同步表单位于应用中的 **Settings** → **Sync & Backup** 标签页 → **Sync** 部分。下方结构与代码库中的表单一致。

## 配置位置

1. 打开 **Settings**（齿轮图标）。
2. 打开 **Sync & Backup** 标签页。
3. 在 **Sync** 部分，启用 **Enable syncing**，并从下拉框中选择 **Sync provider**。

表单的其余部分取决于所选提供方。常见选项（同步间隔、仅手动、加密）在各提供方部分之后说明。

---

## SuperSync (Beta)

- **Info：** 应用会显示简短说明：SuperSync 可跨设备实时保持任务同步，且数据存储在同步服务器上。SuperSync 目前处于 Beta。
- **获取令牌：** 点击 **Open Server & Get Token**，在浏览器中打开服务器登录页。登录后，复制你的访问令牌。
- **Access Token：** 将令牌粘贴到 **Access Token** 字段。SuperSync 必填。
- **多台设备：** 你可以在每台设备上复用同一访问令牌，或在每台设备上分别登录以获取另一个令牌。两种方式都连接到同一 SuperSync 账户并同步相同数据。添加设备时不要使用 **Revoke & Replace Token**；它会使所有现有令牌失效并断开每台设备。
- **Advanced：** 在 **Advanced** 下，可设置自定义 **Server URL**（使用官方服务器时保持默认）。此处也可 **Enable Encryption** 以启用端到端加密；应用会显示关于密码丢失以及服务器数据被替换的警告。
- **Encryption：** 若已启用加密，可从同一表单 **Change Password** 或 **Disable Encryption**。这些操作会替换服务器数据，并要求所有设备使用相同密码（或使用新密码重新上传）。

SuperSync 使用固定同步间隔，不显示 **Sync interval** 或 **Only sync manually** 选项；这些适用于基于文件的提供方。

---

## Dropbox

- **Authentication：** 选择 Dropbox 时，应用使用 OAuth：你会被带到 Dropbox 登录并授权应用。应用中不存储 Dropbox 密码；仅保留令牌。
- 会出现 **Sync interval** 与 **Only sync manually**（见下文）。**Encryption** 在基于文件的提供方的 **Advanced** 下可用；你可设置客户端加密密钥，以便 Dropbox 中的数据以加密形式存储。

---

## OneDrive

仅在 **desktop (Electron)** 与 **Android** 上可用；不适用于 web app。

OneDrive 同步需要你自己的 **Microsoft Entra**（Azure AD）应用注册 — 应用不附带内置的 OneDrive client ID，因此 **Use my own app registration** 选项始终开启。在 [Microsoft Entra admin center](https://entra.microsoft.com) 的 **App registrations** → **New registration** 下创建，然后将其配置为 **public client**：

1. **Redirect URI：** 在 **Mobile and desktop applications** 平台下添加重定向 URI（**Authentication** → **Add a platform** → **Mobile and desktop applications**）：
   - **Desktop (Electron)：** `superproductivity://oauth-callback/onedrive`
   - **Android / manual fallback：** `https://login.microsoftonline.com/common/oauth2/nativeclient`

   **不要**将这些注册到 **Web** 或 **Single-page application (SPA)** 平台下 — 否则令牌兑换会失败并返回 `HTTP 400`（例如 `AADSTS9002327`）。

2. **Allow public client flows：** 在 **Authentication** 中，将 **Allow public client flows** 设为 **Yes**。Super Productivity 使用 PKCE 认证且不发送 client secret；若为 **No**，登录看似成功，但令牌步骤会失败并返回 `HTTP 400 Bad Request`（`AADSTS7000218: ... 'client_assertion' or 'client_secret'`）。
3. **API permissions：** 在 **API permissions** 下，添加 Microsoft Graph **delegated** 权限 `Files.ReadWrite.AppFolder` 与 `offline_access`。

然后在 Super Productivity 中：

- **Application (Client) ID：** 必填。来自你的应用注册的 **Application (client) ID**。
- **Tenant ID：** 个人或多租户登录使用 `common`，或使用你的特定租户 ID。
- **Sync Folder Path：** 存储在你的 OneDrive **App Folder** 内（例如 `Super Productivity`），而非 OneDrive 根目录。
- **Authenticate：** 通过应用提供的链接登录。在桌面上重定向会自动捕获；在 Android/手动模式下，你需将授权码复制回应用。
- **Sync interval**、**Only sync manually** 与 **Encryption**（在 **Advanced** 下）适用，与其他基于文件的提供方相同。

**登录看似成功后出现 `HTTP 400 Bad Request` 的故障排除：** 这是未配置为 public client 的注册的典型表现。确认 **Allow public client flows** 为 **Yes**，且重定向 URI 位于 **Mobile and desktop applications** 下（而非 Web/SPA）。应用会在错误消息中显示底层的 `AADSTSxxxxx` 代码，以帮助定位原因。

## Nextcloud

- **Server URL：** 必填。例如：`https://cloud.example.com` 或 `https://example.com/nextcloud`。
- **Username：** 必填。必须是你的 Nextcloud **user ID** — **不是**你的电子邮件地址或显示名称。要找到它，在 Nextcloud 中打开 **Files**，点击**左下角的设置齿轮**，并从那里显示的 **WebDAV** URL 中复制 `<user-id>`（`.../remote.php/dav/files/<user-id>/`）。不要使用文件夹地址栏中的数字 — 那是文件夹 ID，不是你的 user ID。（Nextcloud 接受电子邮件/登录名用于*认证*，因此此处填错时登录往往仍能通过，但随后会因文件路径不存在而以 **404** 失败。）
- **Login name / email (optional)：** 仅当你的 Nextcloud 登录名是电子邮件或其他与 **Username** 不同的值时使用。若留空，应用使用 **Username** 进行认证。
- **App Password：** 必填。在 Nextcloud 的 **Settings** → **Security** → **App passwords** 下创建。
- **Sync Folder Path：** 相对于账户 WebDAV 文件根目录的路径，用于存放同步文件（例如 `/super-productivity` 或 `/`）。这不是服务器的内部文件系统路径。
- **Sync interval** 与 **Only sync manually** 适用。**Encryption** 在基于文件的提供方的 **Advanced** 下可用。

---

## WebDAV (experimental)

- **Info：** 表单说明通用 WebDAV 同步按原样提供且不提供支持。若你使用 Nextcloud，请改用 **Nextcloud** 同步选项。在浏览器中可能出现 **CORS** 提示：你可能需要允许应用向你的 WebDAV 服务器发起 CORS 请求。使用风险自负。
- **Base URL：** 必填。例如：`https://webdav.example.com/remote.php/dav/files/yourUserName/` 或服务器提供的 WebDAV 基 URL。
- **Username** 与 **Password：** WebDAV 必填。
- **Sync Folder Path：** 相对于 WebDAV 服务器根目录的路径，用于存放同步文件（例如 `/super-productivity` 或 `/`）。这不是服务器的内部文件系统路径。
- **Sync interval** 与 **Only sync manually** 适用。**Encryption** 在基于文件的提供方的 **Advanced** 下可用。

---

## Local File (experimental)

仅在 **desktop (Electron)** 与 **Android** 上可用；不适用于 web app。

- **Info：** 表单说明本地文件同步将数据存储在你设备上的文件夹中，且你应**不要**使用文件同步工具（例如 Syncthing、Resilio）在设备之间同步该文件夹——它们可能导致冲突。对于多设备同步，建议使用 WebDAV、Dropbox 或 SuperSync。
- **Sync folder path：** 必填。在桌面上，使用 **Sync folder path** 按钮打开文件夹选择器并选择同步文件的存放位置。在 Android 上，使用同一按钮打开 Storage Access Framework (SAF) 并选择文件夹。所选文件夹仅在你按下 **Save** 时生效；关闭对话框而不保存会保留之前的文件夹。
- **Sync interval** 与 **Only sync manually** 适用。**Encryption** 在基于文件的提供方的 **Advanced** 下可用。

---

## 常见选项（Dropbox、OneDrive、Nextcloud、WebDAV、Local file）

- **Sync interval：** 应用自动同步的频率。对 SuperSync 以及开启 “Only sync manually” 时隐藏。
- **Only sync manually (disable automatic sync)：** 勾选后，仅在你触发时同步（例如通过同步按钮）。仅对基于文件的提供方（Dropbox、OneDrive、Nextcloud、WebDAV、Local file）显示。

---

## Encryption

- **SuperSync：** 加密在 SuperSync 区块中配置（Enable Encryption、Change Password、Disable Encryption）。服务器可仅存储加密数据；你管理密码，且必须在所有设备上使用相同密码。
- **基于文件（Dropbox、OneDrive、Nextcloud、WebDAV、Local file）：** 在 **Advanced** 下，可 **Enable** 客户端加密。你设置加密密钥；应用在发送前加密数据。密钥不会发送给提供方。你必须在下次同步前在每台设备上设置相同密钥。若加密已启用，表单会显示密码已设置，并提供 **Change Password** 或 **Disable Encryption**（或 **Remove Encryption**）。启用或禁用加密会替换远端数据（Dropbox 文件、Nextcloud/WebDAV 文件夹或本地文件），并影响所有设备。
