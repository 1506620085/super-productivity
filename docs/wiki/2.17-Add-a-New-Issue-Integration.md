# 添加新的 Issue 集成

新的 issue 跟踪器与日历集成应实现为 **issue-provider
插件**。插件将提供商特定的配置、API 调用与数据映射保持在核心应用之外，并获得稳定的 `plugin:<plugin-id>` 提供商键。

请从仓库的
[plugin-first integration guide](https://github.com/super-productivity/super-productivity/blob/master/docs/add-new-integration.md)
开始。该指南涵盖当前的 `IssueProviderPluginDefinition`、manifest、凭据存储、打包与验证要求。当前打包的提供商位于
[`packages/plugin-dev/`](https://github.com/super-productivity/super-productivity/tree/master/packages/plugin-dev)
下，可作为实现示例。

除非维护者已批准存在插件 API 无法满足的仅核心需求，否则不要将提供商添加到 `src/app/features/issue/providers/`、核心联合类型、默认值或配置表单中。现有内置提供商仅因维护需要而保留在核心中。
