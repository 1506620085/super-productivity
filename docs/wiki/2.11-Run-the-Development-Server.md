# 运行开发服务器

如何在本地运行 Super Productivity 进行开发，或在 GitHub Codespaces 中运行。

## 方式 1：本地

### 前置条件

- Node.js 20 或更高版本（[nodejs.org](https://nodejs.org)）
- Git

### 本地：克隆并安装

```bash
git clone https://github.com/super-productivity/super-productivity.git
cd super-productivity
npm i -g @angular/cli
npm i
npm run env
```

`npm run env` 会一次性创建或更新环境文件；若你新增或修改了变量，请重新运行。

### 本地：启动前端

```bash
ng serve
```

打开 [http://127.0.0.1:4200](http://127.0.0.1:4200)。对于大多数 UI 与前端工作，这已足够。[Redux DevTools](https://chrome.google.com/webstore/detail/redux-devtools/lmhkpmbekcpmknklioeibfkpmmfibljd) 可在浏览器中使用。

### 本地：运行完整应用（Electron）

```bash
ng serve
```

在第二个终端中：

```bash
npm start
```

Electron 窗口将加载开发服务器。

## 方式 2：GitHub Codespaces

1. 在 GitHub 上打开该仓库。
2. 点击 **Code** → **Codespaces** → **Create codespace on main**（或加号图标）。
3. 等待开发容器构建完成。开发服务器通常会自动启动。
4. 打开 **Ports** 标签页，找到转发的端口（例如 4200），使用 **Open in Browser** 或 Ctrl+Click URL 打开应用。

VS Code 设置会在 codespace 中同步。若要更改开发环境，请按
[Codespaces 文档](https://docs.github.com/en/codespaces/setting-up-your-project-for-codespaces/adding-a-dev-container-configuration/introduction-to-dev-containers)
编辑 `.devcontainer/devcontainer.json`。
