# 从备份恢复数据

要了解备份包含哪些内容以及导入如何替换你的数据，见 [[4.23-Managing-Your-Data]] 与 [[3.06-User-Data]]。

## 标准方法：通过导入/导出恢复

1. 打开 **Settings**（侧边栏或顶栏中的齿轮图标）。
2. 打开 **Sync & Backup** 标签页。
3. 在 **Automatic Backups** 部分，备份位置会显示在 **desktop**（Electron）上：一行 “Backups are saved to:” 后跟路径。记下或复制该路径，以便在需要时定位备份文件。
4. 在同一标签页中，使用 **Import/Export** 部分。点击 **Import from File** 并选择你的备份文件（例如来自自动备份文件夹）。在警告出现时确认——导入会**替换全部当前数据**且无法撤销。

若应用未找到数据但检测到备份（例如在启动时），可能会提示你恢复最新备份；你可以接受该提示，而不使用 Import from File。

## Android：恢复最新自动备份

在 Android 上，自动备份存储在应用数据内部，而非可见的备份文件。要恢复最新可用插槽：

1. 打开 **Settings**。
2. 打开 **Sync & Backup** 标签页。
3. 在 **Automatic Backups** 部分，点击 **Restore latest automatic backup**。
4. 确认警告。这会用所选自动备份替换当前本地数据。

仅将其用作恢复操作。若已配置同步，恢复的数据会像备份导入一样处理，并可能在下次同步时覆盖其他已同步设备。

## SuperSync 安全完整性错误

仅在某台已更新设备仍显示完整、最新数据时使用此恢复方法。**Force Overwrite 会替换 SuperSync 服务器上的副本，并将该设备的数据传播到其他每台设备。切勿从空白、新安装、不完整或过时的设备上运行。**

1. 保持其他每台设备离线。不要清除或卸载拥有完整数据的那台设备。
2. 在拥有完整数据的设备上，更新 Super Productivity，并确认近期任务、项目与归档均存在。
3. 前往 **Settings → Sync & Backup → Import/Export**，导出数据，并安全保存该明文备份。
4. 在 **Settings → Sync & Backup → Sync** 中，打开 **Advanced**，选择 **Force Overwrite**，并确认替换。
5. 等待同步成功完成后再重新连接其他设备。
6. 在重新连接其他设备前先更新它们，逐台同步，并验证恢复的数据。在每台设备都正确之前保留备份。

若没有任何设备拥有经验证的完整副本，请勿使用 Force Overwrite，也不要重置服务器账户。保持其余设备不变，并联系支持人员，以便检查保留的历史记录。

## 替代方法：先清除应用数据，再导入

若应用无法正常启动（例如 [任务状态不一致](https://github.com/super-productivity/super-productivity/issues/3052)），请先清除本地数据，再导入备份：

1. 定位你的备份文件（并可选地制作一份副本）。
2. 启动应用。
3. 打开开发者工具：**Ctrl+Shift+I**（Windows/Linux）或 **Cmd+Option+I**（macOS）。
4. 打开 **Application** 标签页，然后在左侧边栏打开 **Storage**。
5. 点击 **Clear site data**。
6. 重新加载应用：**Ctrl+R**（Windows/Linux）或 **Cmd+R**（macOS）。
7. 在 Super Productivity 中，前往 **Settings → Sync & Backup → Import/Export**，使用 **Import from File** 选择你的备份。
