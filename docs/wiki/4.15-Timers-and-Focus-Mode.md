# 计时器与 Focus Mode

Super Productivity 中的 Focus Mode 针对任务型工作的核心挑战：**在干扰与上下文切换面前，保持持续注意力与结构化工作时段**。应用旨在通过时间盒、时间追踪、休息提醒、抗拖延功能以及类似番茄钟的计时器，帮助你保持条理与专注——它们共同支持健康、高效的习惯。计时器与专注被当作**一等功能**：有专门配置、行为清晰的不同模式，并与任务追踪和指标深度集成。了解 Focus Mode 解决什么问题、它与时间盒和深度工作的关系、应用在使用计时器时对专注有何假定，以及计时器如何影响你的行为，有助于你有效使用它。

你可从桌面与移动布局主页眉中的专注按钮进入 Focus Mode。键盘快捷键列在 [[3.03-Keyboard-Shortcuts]]。

关于追踪任务时时间如何记录，请参阅 [[4.14-How-Time-Is-Logged]]。Focus Mode 设置（从任务追踪自动启动、tick 音效、准备画面、休息等）在 [[3.02-Settings-and-Preferences]]。

## Focus Mode 解决什么问题？

因**干扰与上下文切换**导致的生产力损失，正是应用明确试图减少的。Focus Mode 为你提供：

- **结构化工作时段** — 计时器以及清晰的「工作」与「休息」阶段，让你能投入一段时间块，而不是无结构地工作。
- **时间盒** — 固定或灵活的时间盒，便于规划工作多久、何时休息。
- **觉察** — 可选的 tick 音效与会话完成通知，让你保持在场并知道时间块何时结束。
- **与任务追踪集成** — 专注会话与你正在追踪的任务同步启动与暂停，因此「专注时间」与「任务时间」保持对齐。

应用的**指标**也反映这一点。它们可将你的一天归类为多种状态，包括理想的 **deep-flow（深度心流）** 状态（高生产力且高可持续性），以及 **drift（漂移）** 状态（低生产力且低可持续性——常表示注意力或专注问题）。这鼓励你不仅反思*工作了多少*，也反思*如何*工作：持续专注 vs 碎片化注意力。

## Focus Mode 与时间盒及深度工作的关系

Focus Mode 实现了**三种不同的时间盒策略**，各自对应不同的生产力方法：

### Pomodoro 模式

**Pomodoro（番茄钟）** 是经典的固定工作/休息时长时间盒：

- **工作会话** — 设定时长（默认常为 25 分钟；可配置）。你工作到计时器达到该时长。
- **短休息** — 每次工作会话后，有一次短休息（常为 5 分钟）。
- **长休息** — 每隔若干周期（常为 4），有一次更长休息（例如 15 分钟）以恢复。

应用可在休息后自动开始下一工作会话，因此你可以连续运行多个周期。Pomodoro 很适合**有纪律、基于间隔的工作**：边界清晰、定期休息、节奏可预期。

### Flowtime 模式

**Flowtime** 支持**无固定会话时长的开放式深度工作**：

- **无固定时长** — 会话没有预设结束；计时器运行到你选择停止为止。
- **无自动完成** — 应用绝不会自行结束 Flowtime 会话。这避免在你处于心流时打断你。
- **无自动休息** — 休息不是由应用启动；你想休息时再开始。这样你仍掌控何时离开。

Flowtime 适用于你希望**持续专注而没有硬性停止**的时候：你开始会话，工作到完成或需要休息，然后手动结束。计时器仍会跟踪你已工作多久，以便你看到已用时间。

### Countdown 模式

**Countdown（倒计时）** 是**自定义时长的时间盒**：

- **你设定长度** — 每次开始会话时，你选择时长（或使用建议/默认值，例如上次使用的时长）。
- **计时器达到该时长并停止时会话结束** — 与 Pomodoro 工作会话相同的完成逻辑，但时长由你按会话选择。
- **无自动休息** — 与 Pomodoro 不同，Countdown 会话后应用不会自动开始休息；你决定接下来做什么。

Countdown 适用于你希望**灵活时间盒**的时候：例如「我专注 45 分钟做这件事」或「我做 20 分钟再切换」。

### 最优专注与可持续深度工作

应用的设计体现了**可持续深度工作**有自然上限的理念。指标使用**每日 4 小时（240 分钟）的最优专注目标**。这与研究表明：超过一定量的专注工作后，收益递减而疲劳增加——相一致。因此 Focus Mode 与指标的目标不是最大化「更多小时」，而是支持**专注且可持续**的工作：有足够结构保护注意力，又有足够灵活性（尤其在 Flowtime 中）在心流出现时加以保护。

## 使用计时器时应用对专注有何假定

若干假定驱动计时器行为以及专注如何评估。

### 何时认为会话已完成

**工作会话**在以下情况被视为完成：

1. **已用时间达到设定时长**（对有时长的模式：Pomodoro 与 Countdown）。
2. **计时器已停止** — 完成处理发生在计时器不再运行时，而不仅仅是数字越过阈值时。无论内部多久更新一次计时器，行为都保持一致。

已用时间始终从**会话开始时**计算到**现在**，因此即使更新间隔变化，时长也准确。对于 **Flowtime**，没有设定时长，因此会话**绝不会自动完成**；你必须自行结束。这保留了 Flowtime「不打断」的设计。

### 按模式区分的完成行为

- **Pomodoro** — 当工作计时器达到会话长度时，会话完成，应用可自动开始休息（短或长，取决于周期）。休息后，可自动开始下一工作会话。
- **Countdown** — 当计时器达到你选择的时长并停止时，会话完成。因为没有自动休息或下一会话，应用会确保不会静默结束。若专注浮层已打开，你进入 **Session Done（会话完成）** 画面。若你已隐藏浮层并继续做事，则会出现可关闭的横幅（以免打断工作），并提供返回 Session Done 画面的快捷方式；若你已完全切离应用，还会收到系统通知。
- **Flowtime** — 会话永不自动完成。你决定何时停止；没有自动休息。

因此「会话完成」在各模式下含义不同：在 Pomodoro 中它触发休息（并可能触发下一会话）；在 Countdown 中它只是结束；在 Flowtime 中只有你说结束才结束。

### 专注平衡与可持续性

应用的**可持续性指标**假定**更多专注时间并不总是更好**。它对专注平衡使用**倒 V 曲线**：在最优量（例如 4 小时）之内，更多专注提升可持续性；超过之后，**过度专注会被惩罚**（例如指数衰减）。**生产力指标**则不同：超过目标的专注不再获得额外专注加分，也不被惩罚，而整体生产力分数仍可能通过总工作加分变化。这反映了**认知疲劳是非线性的**：远超可持续范围并不能改善结果，还会损害可持续性。因此系统鼓励你重视**可持续**专注，而非最大小时数。

## 计时器如何影响你的行为

计时器通过多种机制影响你的工作方式。

### 听觉反馈

在设置中启用时，应用可在工作会话期间**播放 tick 音效**（通常每秒一次，音量降低以免干扰）。这让你微妙地意识到时间在流逝且你正处于专注块中，而不必盯着屏幕。

### 会话完成通知

当**工作会话**或**休息**完成时，应用可以：

- **播放声音** — 即使窗口未聚焦你也能注意到。
- **发送系统通知** — 当 Countdown 会话完成且你已切离应用时，跨平台 OS 通知（桌面、网页与移动）会报告，即使声音关闭也能提醒你。应用已聚焦时会跳过，因为下方的屏幕呈现已足够醒目。
- **聚焦或闪烁窗口** — 在桌面上，应用可将自身置于前台或闪烁边框，让你看到会话已结束。
- **呈现 Session Done 画面或横幅** — 当 Countdown 会话在无自动后续时完成：若专注浮层已打开则显示 **Session Done** 画面；若已隐藏则出现可关闭横幅，以免把你从正在做的事中拽出。无论如何，会话都不会静默停止。
- **显示视觉反馈** — 例如进度条或屏幕上表示时间块已完成的提示。

这种多通道反馈能清楚表明何时从工作切到休息、从休息切回工作，或 Countdown 会话何时结束。

### 与任务追踪的深度集成

Focus Mode 与时间追踪**双向**协作：

- **任务追踪 → 专注** — 当你**开始**追踪任务时，应用会恢复已暂停的专注会话。若启用了 **Start a focus session when I start tracking a task（开始追踪任务时启动专注会话）**，追踪任务也可开始新的专注会话。若你在休息中并开始追踪任务，应用可跳过休息并开始工作，使会话与任务对齐。
- **专注 → 任务追踪** — 开始 Focus 会话会开始追踪其选定的任务。当你暂停会话（例如休息）时，应用也可暂停任务追踪，以免在休息期间记录时间。当你恢复时，两者都恢复。

会话开始前，在 Focus Mode 浮层中选择任务只是为该会话准备任务；不会开始记录任务时间。按下 **Start（开始）** 会同时激活所选任务与 Focus 计时器。在按下 Start 之前关闭浮层，不会改变任何现有任务追踪。

这形成了**双向链接**：启动或暂停任务会影响专注会话，启动或结束专注会话（或休息）也会影响正在追踪的内容。结果是「专注时间」与「已记录任务时间」保持同步。

### 质量指标与专注的角色

应用的**生产力分数**综合多个因素。专注时间是其中之一（权重常约 30%）：朝专注目标推进会提升分数。但**影响（impact）**（你自己对工作价值的评估）权重更高（例如约 65%）。因此系统鼓励你**反思工作价值**，而不仅是花费时间。专注时间会得到奖励，但分数的主要驱动是工作是否重要。这支持在「我专注了吗？」与「我做了有意义的事吗？」之间取得平衡。

## 为何专注是一等功能

Focus Mode 不是次要附加；它被设计为**工作流的核心部分**。

### 专门设计与状态

Focus Mode 有自己的**计时器状态**（运行中、开始时间、已用、时长、工作 vs 休息）、**界面画面**（任务选择、时长选择、准备、主计时器、会话完成、休息），以及**会话元数据**（模式、周期、上次完成时长、暂停的任务）。计时器是「此会话已运行多久？」的**唯一真实来源**，因此界面与依赖会话长度的任何逻辑保持一致。

### 按模式的策略

每种模式（**Pomodoro**、**Flowtime**、**Countdown**）都有**明确行为**：不同的会话长度、不同的休息规则、不同的完成行为。应用不把它们当作「同一个计时器、不同数字」；而是当作**不同策略**。因此 Pomodoro 始终有休息与周期；Flowtime 永不自动完成；Countdown 始终让你设定时长。这使每种模式可预期且有目的。

### 配置与集成

Focus Mode 有**多项专门设置**（例如任务追踪开始时自动启动 Focus、显示准备画面、播放环境音、休息时暂停任务追踪，以及启用 Pomodoro 加班）。这些选项表明专注旨在**可配置**以适配你的工作流。该功能也**编织进应用**：会话生命周期（开始、tick、完成）、休息处理、任务追踪同步以及指标都依赖专注状态。因此专注**对工作流至关重要**，而不是可以忽略的侧边面板。

### 可持续生产力作为目标

设计将**专注视为需要培养与维持的技能**。因此应用提供：

- **结构化模式** — 让你选择适合工作方式的节奏（Pomodoro、Flowtime、Countdown）。
- **准备阶段** — 让你在计时器开始前在心理上投入（除非你跳过）。
- **可持续性指标** — 让你看到自己是处于可持续模式（例如深度心流），还是有倦怠风险（例如过载）或漂移。

4 小时最优专注目标以及对过度专注的惩罚，强化了目标是**可持续生产力**，而不是不惜代价的最大小时数。

## 小结

- **Focus Mode** 应对**持续注意力与结构化会话**；它是具有自身状态、模式与设置的一等功能。
- **三种模式**：**Pomodoro**（固定工作/休息/周期）、**Flowtime**（开放式、无自动完成）、**Countdown**（每次会话自定义时长）。
- **会话完成**：对 Pomodoro 与 Countdown，当已用 ≥ 时长且计时器停止时工作会话完成；**Flowtime 永不自动完成**。
- **专注平衡**：指标假定**最优专注目标**（例如每天 4 小时）并**惩罚过度专注**以支持可持续性。
- **行为**：环境音、会话完成通知以及同步的任务追踪，将专注与你实际如何工作联系起来；从任务追踪自动启动 Focus 是可选的。
- **质量**：生产力分数对**影响**的权重高于**专注时间**，因此鼓励你反思价值，而不仅是时间。
