# 同步集成对比

本参考对比 Super Productivity 中可用的 **同步提供方**：各自如何存储与同步数据、支持哪些平台、认证如何工作，以及是否提供可选加密。可用于选择同步提供方，或了解数据如何在设备间移动。

集成如何工作（issue 提供方与同步提供方）的概述，见 [[4.24-Integrations]]。冲突处理、备份行为以及数据存储位置，见 [[4.23-Managing-Your-Data]] 与 [[3.06-User-Data]]。**Issue** 提供方（Jira、GitHub 等）的对比见 [[3.07-Issue-Integration-Comparison]]。

## 同步提供方做什么

同步提供方在本应用实例与远程位置或另一设备之间 **同步你的全部 Super Productivity 数据**（任务、项目、标签、时间跟踪、设置、归档等）。它们**不**从 Jira、GitHub 或其他 issue 跟踪器导入 issue；那些由 issue 提供方处理。应用中的所有同步都是 **本地优先** 且 **基于操作** 的：你的设备持有主副本，变更以操作（或包含状态与操作的同步文件）发送到远程侧。一次只配置一个同步提供方。

## 对比摘要

| Provider         | Platform     | Authentication                         | Optional encryption         | Typical use                                  |
| ---------------- | ------------ | -------------------------------------- | --------------------------- | -------------------------------------------- |
| Nextcloud        | All          | Username, optional login, app password | Yes (client-side key)       | Nextcloud files sync                         |
| WebDAV           | All          | URL, username, password                | Yes (client-side key)       | ownCloud and other WebDAV servers            |
| Dropbox          | All          | OAuth 2.0 (no password stored)         | Yes (client-side key)       | Cloud backup, cross-device sync              |
| SuperSync (beta) | All          | URL, username/password or token        | Yes (E2E, server-supported) | Dedicated sync server, self-hosted or hosted |
| Local file       | Desktop only | None (folder path)                     | Yes (client-side key)       | Single-device local or network-folder backup |

**注意：** SuperSync 非常新，仍处于 beta。在 SuperSync 稳定之前，生产使用请优先选择 Nextcloud、WebDAV、Dropbox 或本地文件。

**加密时机：** 首次启用基于文件的提供方（Nextcloud、WebDAV、Dropbox、OneDrive 或本地文件）时，设置流程中会提供设置加密密码的选项。若设置，密码会随同步配置保存，因此第一次上传——以及之后的每次上传——都会加密；本设备上传的任何内容都不会以未加密形式离开。加密保持可选：你可以跳过提示，之后再在同步设置中启用、更改或禁用。

**降级保护：** 当基于文件的提供方启用加密时，应用会拒绝未加密的远程同步文件，而不是导入它或自动关闭加密。若你有意在另一台受信任设备上禁用了加密，请在本设备上有意更改加密设置后再同步。否则请保持加密启用，并检查远程账户或连接是否有意外变更。

## 各提供方详情

### Nextcloud

- **兼容于：** Nextcloud 文件 WebDAV。
- **配置：** 服务器 URL、用户名、可选的单独登录名/邮箱、应用密码，以及同步文件夹路径。用户名用于 `/remote.php/dav/files/<username>/`；可选登录名/邮箱仅用于用不同值认证的服务器。
- **加密：** 可选客户端加密；你设置的加密密钥不会发送到服务器。
- **平台：** 在桌面（Electron）、Web 与移动端可用。在浏览器中，CORS 可能阻止 WebDAV 请求；应用可能建议使用桌面版以获得可靠同步。
- **并发写入：** 提供强 ETag 的服务器获得原子冲突保护。ETag 弱或缺失的服务器使用尽力内容检查；在这些服务器上请避免多台设备在完全同一时刻同步同一文件夹。

### WebDAV

- **兼容于：** Nextcloud、ownCloud 以及任何兼容 WebDAV 的服务器。
- **配置：** 基础 URL、用户名、密码，以及服务器上可选的同步文件夹路径。
- **加密：** 可选客户端加密；你设置的加密密钥不会发送到服务器。
- **平台：** 在桌面（Electron）、Web 与移动端可用。在浏览器中，CORS 可能阻止 WebDAV 请求；应用可能建议使用桌面版以获得可靠同步。
- **高级方案：** 某些存储提供方可通过外部工具暴露为本地 WebDAV。关于通过 rclone 使用 Proton Drive，见 [[2.19-Sync-Proton-Drive-via-rclone]]。这不是内置的 Proton Drive 提供方。

### Dropbox

- **配置：** OAuth 2.0；你用 Dropbox 账户登录。应用中不存储 Dropbox 的用户名/密码；授权后应用存储令牌。
- **加密：** 可选客户端加密；你设置加密密钥。数据可加密存储在你的 Dropbox 中，仅本应用（持有密钥时）可读。
- **平台：** 在桌面、Web 与移动端可用。

### SuperSync（beta）

- **是什么：** 专为 Super Productivity 设计的同步服务器。可自托管或使用托管实例。**SuperSync 非常新且仍处于 beta；** 在稳定之前，生产使用请考虑 Nextcloud、WebDAV、Dropbox 或本地文件。
- **配置：** 服务器基础 URL，然后是用户名/密码或访问令牌；可选同步文件夹路径。可在服务器侧启用可选的 **端到端加密**，使服务器仅存储加密数据。
- **加密：** 可选；启用时服务器支持 E2E 加密。你管理加密密钥；服务器看不到明文数据。
- **平台：** 在桌面、Web 与移动端可用。同步使用与其他提供方相同的基于操作的模型，但直接与 SuperSync 服务器通信（不经过通用云文件夹中的中间文件）。
- **实时跟踪在线状态（实验性，需主动启用）：** 在同步设置 → 高级 → **在其他设备上显示实时跟踪** 下启用。实时连接处于活动状态时，正在跟踪时间的设备会显示在你的其他设备上——标题栏中的小芯片（以及静默的 Android 通知）会标出设备与任务，并提供可远程结束会话的停止按钮。空闲暂停显示为「已暂停」，无停止按钮。这仅是实时镜像：从不持久化到服务器（仅在设备连接时有短暂的内存槽位），复用现有连接（无额外连接），且在启用同步加密时始终端到端加密。仅 SuperSync；其他提供方无实时通道。
- **网络中断：** 临时连接中断会重试。若请求仍失败，本地变更留在设备上，之后可再试同步。
- **已连接设备：** 同步设置 → 高级 → **显示已连接设备** 列出最近与账户同步过的设备（最近活跃的 100 台），含平台、客户端 ID 与上次同步时间。对 SuperSync 账户的访问按账户而非按设备授予——是单个长期令牌，而非每设备一个——因此移除单个条目不会阻止该设备同步，也不提供按设备吊销。相反，**退出其他设备**（同一对话框中）会使除你按下时所在设备新签发的令牌外的所有令牌失效：在设备丢失或售出时使用。已退出的设备停止同步，需要新签发的令牌才能重新连接；退出期间在其上所做的变更保存在本地，重新认证后上传。停止同步的设备在服务器保留期后自动从列表中消失。

### 本地文件同步

- **是什么：** 将同步文件写入本地或网络可访问的文件夹（例如共享驱动器或 NAS）。
- **配置：** 仅文件夹路径；无远程账户。
- **加密：** 可选客户端加密，密钥由你设置。
- **平台：** **仅桌面（Electron）。** 在 Web 应用或移动端不可用，因为这些环境无法可靠访问任意本地或网络路径。
- **重要限制：** 将其用作单设备备份目标。不要用 Syncthing、Resilio、云盘客户端或类似工具在设备间镜像该文件夹：本地文件系统访问无法原子协调并发写入者，同时同步可能互相覆盖。多设备同步请使用 Nextcloud、WebDAV、Dropbox 或 SuperSync。

## 选择提供方

- **Nextcloud** — 若你已有 Nextcloud，并希望应用为你构建 WebDAV 文件 URL，请使用。
- **WebDAV** — 若你有 ownCloud 或其他 WebDAV 服务器，或需要自行提供完整 WebDAV 基础 URL，请使用。
- **Dropbox** — 用于无需自建服务器的云端同步；OAuth 使账户凭据不进入应用配置。
- **SuperSync（beta）** — 当你想要专用同步服务与可选的服务器侧 E2E 加密时使用。请记住它非常新且仍处于 beta。
- **本地文件** — 在桌面上用于向本地或网络文件夹（例如外置驱动器或 NAS）做单设备备份，而非在设备间镜像的文件夹。

逻辑冲突解决（例如两台设备更改同一数据时）对所有提供方使用相同的操作规则。传输保证仍有差异：本地文件仅为单写入者，WebDAV 原子写保护取决于强 ETag 支持。见 [[4.23-Managing-Your-Data]]。
