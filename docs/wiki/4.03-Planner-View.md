# 规划器视图（Planner View）

**规划器（Planner）** 视图帮助你跨多天组织任务。与专注于执行工作的视图（如今日视图或项目视图）不同，规划器面向未来，让你可以将任务安排到未来的日期、查看工作随时间的分布，并整合日历事件与重复任务。

## 规划器显示内容

规划器显示一个滚动的未来日期窗口（通常约 15 天，取决于你的工作日设置）。对于每一天，你会看到：

- **安排在该日的任务** — 你已分配到该日期的任务
- **计划工作量** — 该日剩余任务预估，加上有时限的日历事件与重复项时长；在启用工作时间时，会对照可用工作时间显示
- **容量百分比** — 计划工作量占用可用工作时间的比例
- **日历事件** — 来自你已连接的外部日历的事件
- **重复任务投影** — 将在该日出现的重复任务实例

## 规划与调度

规划器使用**按日规划**：

- 设置任务的截止日期（计划在哪一天）
- 不设置具体时间
- 对于今日：任务出现在今日视图中，并使用今日的排序
- 对于未来日期：任务出现在规划器中该日的列中

**调度**（精确到时间）则不同：

- 同时设置日期和具体时间
- 带有具体时间的任务会从规划器中移除（它们属于日程视图）
- 在日程视图中创建带有开始和结束时间的条目

因此，你可以在规划器中将任务规划为“周三”，或在日程中将其调度为“周三下午 2 点”。

## 已规划但未完成

当你为某一天规划了任务但未完成时：

- **对于今日** — 任务保留在今日视图的排序中，并同时出现在今日视图和规划器的今日列中
- **对于未来日期** — 任务保留在规划器中该日的列中
- **自动清理** — 已过去的日期会自动从规划器中移除
- **已删除的任务** — 你删除的任务会自动从规划器日期中移除

## 重复任务与日历事件

规划器显示：

- **重复任务投影** — 将在发生日出现的重复任务实例，包括所创建实例将具有的项目和标签
- **无具体时间的重复任务** — 作为各日列中的独立项显示
- **有具体时间的重复任务** — 出现在已调度项时间线中（日程视图）
- **日历事件** — 外部日历事件合并到同一时间线视图中

## 与其他视图的区别

| 方面 | 规划器视图 | 今日视图 / 项目视图 |
| -------------------- | ----------------------------------- | -------------------------------------- |
| **组织方式** | 按日期（日列） | 按项目、标签或今日列表 |
| **时间精确度** | 仅按日（无具体时间） | 可通过调度设置具体时间 |
| **侧重点** | 面向未来的规划 | 当前工作与执行 |
| **重复任务** | 作为未来日期上的投影显示 | 由重复配置处理 |
